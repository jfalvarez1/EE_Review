Analog Signal Conditioning for ADCs

Before digitizing, analog signals typically need conditioning: amplification, filtering, level shifting, and protection. Poor conditioning wastes ADC resolution and introduces errors.

Gain Stage
Match signal to ADC input range
Anti-Alias Filter
Remove frequencies > fs/2
Level Shift
Center signal in ADC range
Protection
Clamp to ADC abs max
Key Insight: The anti-aliasing filter must attenuate signals above fs/2 (Nyquist) to prevent aliased frequencies from appearing in the digitized output. Higher order filters allow sampling closer to the signal bandwidth.

Anti-Alias Filter Requirements

Filter Order Rolloff Attenuation at fs/2 Typical Use
1st order 20 dB/decade ~20 dB (fc = fs/10) 8-10 bit ADCs
2nd order 40 dB/decade ~40 dB (fc = fs/10) 12 bit ADCs
4th order 80 dB/decade ~80 dB (fc = fs/10) 16+ bit ADCs
Rule of Thumb: For an N-bit ADC, the anti-alias filter should provide at least 6×N dB attenuation at fs/2. For a 12-bit ADC, that's 72dB minimum.
