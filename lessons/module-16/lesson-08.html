Class AB Power Amplifier Design

Class AB amplifiers combine the low distortion of Class A with the efficiency of Class B. A small bias current keeps both output transistors slightly conducting, eliminating crossover distortion while maintaining good efficiency.

Amplifier Classes

  • Class A: 100% conduction, 25% max efficiency
  • Class B: 50% conduction, 78.5% max efficiency
  • Class AB: 50-100% conduction, 50-78% efficiency
  • Class D: Switching, 90%+ efficiency

Key Specifications

  • THD: < 0.1% at rated power
  • Damping Factor: > 100
  • Slew Rate: > 10 V/μs
  • Bandwidth: 20 Hz - 20 kHz ±0.5 dB

Class AB Output Stage

The complementary emitter follower with bias spreader diodes (or Vbe multiplier) sets the quiescent current.
