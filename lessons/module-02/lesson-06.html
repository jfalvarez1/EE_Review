Composite Amplifiers

A composite amplifier combines two or more op-amps within a single feedback loop to achieve performance superior to any individual op-amp. This technique allows engineers to optimize different parameters like input characteristics, bandwidth, and output drive independently.

Why Use Composite Amplifiers?

No single op-amp excels at everything. Composite amplifiers let you combine strengths:

How It Works

  • A1 is the precision front-end (low VOS, low noise) with high open-loop gain
  • A2 runs as a unity-gain buffer inside A1's feedback loop
  • A2's errors (VOS, nonlinearity) are divided by A1's open-loop gain
  • The composite inherits A1's precision with A2's output capability

Stability Analysis

The composite amplifier has two nested feedback loops. Stability requires careful frequency compensation.

Stability Consideration

The product A1 × A2 creates very high loop gain at low frequencies, but multiple poles can cause instability. The inner loop (A2) must be stable on its own before closing the outer loop around A1.

Practical Applications

1. High-Current Precision Source

Use case: Driving heavy loads (motors, heaters) with precision control

  • A1: OP07 (VOS = 30µV, Iout = 25mA)
  • A2: OPA548 (Iout = 3A continuous)
  • Result: 30µV precision with 3A drive capability

2. Wideband Precision Amplifier

Use case: Data acquisition with high accuracy and speed

  • A1: LTC1150 (chopper, VOS = 0.5µV)
  • A2: AD8099 (GBW = 3.8GHz)
  • Result: Sub-microvolt offset with MHz bandwidth

3. Low-Noise Photodiode Amplifier

Use case: Optical sensors requiring both sensitivity and drive

  • A1: OPA827 (en = 4nV/√Hz, JFET input)
  • A2: LT1010 (buffer, 150mA output)
  • Result: Ultra-low noise with cable-driving capability

Design Guidelines

Rules for Stable Composite Amplifiers

  1. Inner loop first: Design A2's local feedback for stability before adding A1
  2. Bandwidth separation: A2's bandwidth should be 3-10× higher than A1's closed-loop bandwidth
  3. Phase margin: Aim for >45° in both loops independently
  4. Compensation: Add CF in feedback if oscillation occurs at high frequencies
  5. Power supply decoupling: Each op-amp needs its own bypass capacitors
