Active Filters

Active filters use op-amps with RC networks to create frequency-selective circuits. They offer advantages over passive filters: gain, high input impedance, low output impedance, and no need for inductors.

Filter Order
Number of poles = rolloff rate (6n dB/octave)
Cutoff Frequency
fc = 1/(2πRC)

Sallen-Key Topology

The Sallen-Key is the most common 2-pole active filter topology:

Unity-Gain Lowpass
fc = 1/(2π√(R1×R2×C1×C2))
Q Factor
Q = √(R1×R2×C1×C2)/(C2×(R1+R2))
Sensitivity Warning: Sallen-Key filters are sensitive to component tolerances. Use 1% resistors minimum. 5% components can cause significant deviation from target response.
