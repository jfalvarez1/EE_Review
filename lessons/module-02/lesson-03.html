Active Filters

Active filters use op-amps with RC networks to create frequency-selective circuits. They offer advantages over passive filters: gain, high input impedance, low output impedance, and no need for inductors.

Filter Order
Number of poles = rolloff rate (6n dB/octave)
Cutoff Frequency
fc = 1/(2πRC)

Sallen-Key Topology

The Sallen-Key is the most common 2-pole active filter topology:

Unity-Gain Lowpass
fc = 1/(2π√(R1×R2×C1×C2))
Q Factor
Q = √(R1×R2×C1×C2)/(C2×(R1+R2))
Sensitivity Warning: Sallen-Key filters are sensitive to component tolerances. Use 1% resistors minimum. 5% components can cause significant deviation from target response.

Design Table: 2nd-Order Butterworth

For a unity-gain Sallen-Key, pick equal resistors and let the two capacitors set Q:

Component Lowpass Highpass
R1 = R2 = R choose it — 10 kΩ is a good default R1 = 0.707/(2πfcC), R2 = 1.414/(2πfcC)
C1 (feedback, node 1 to output) 1.414/(2πfcR) C1 = C2 = C
C2 (node 2 to ground) 0.707/(2πfcR) —
Why the lowpass cannot use equal capacitors. Work the transfer function through and you get \(Q = \sqrt{R_1R_2C_1C_2}\,/\,[C_2(R_1+R_2)]\). Set \(C_1 = C_2\) and that collapses to \(\sqrt{R_1R_2}/(R_1+R_2)\), which by the AM–GM inequality can never exceed 0.5 — it hits 0.5 only when \(R_1 = R_2\). Butterworth needs 0.707, so no choice of resistors will get you there with equal capacitors and a unity-gain buffer. You have exactly three ways out: make the capacitors unequal (the table above, and the usual answer), give the buffer a gain of 1.586 and keep equal parts, or use a different topology such as multiple-feedback. The highpass has the ratio the other way up, which is why it can use equal capacitors and unequal resistors.
