DC Errors: Vos, Ib, and Ios

Real op-amps have DC imperfections that cause output errors even with no input signal. Understanding these errors is essential for precision analog design.

Input Offset Voltage (Vos)
Voltage needed at input to force output to zero
Input Bias Current (Ib)
Average DC current into both inputs
Input Offset Current (Ios)
Difference between input bias currents
Key Insight: Vos appears as if a small battery is in series with one input. Ib flows into (or out of) the inputs and creates voltage drops across source impedances.

Error Source Diagram

DC errors can be modeled as voltage and current sources at the op-amp inputs:

Error Model: Vos appears as a small voltage source at the non-inverting input. Bias currents Ib+ and Ib- flow into (or out of, for CMOS) both inputs. The mismatch Ios = |Ib+ - Ib-|.

Bias Current Compensation

Adding a resistor in series with the non-inverting input can cancel Ib-induced errors:

Compensation Resistor
Rcomp = R1 || Rf
Remaining Error
ΔV = Ios × Rcomp

This technique only works when Ios << Ib. For modern JFET and CMOS op-amps, the compensation resistor often does more harm than good (adds noise).

Important: For CMOS op-amps, Ib can be negative (current flows OUT of the inputs) and reverses direction with input voltage. Bias compensation doesn't work well for CMOS!

Temperature Effects

All DC errors worsen with temperature. The offset voltage drift (typically in µV/°C) is often the dominant error in precision circuits.

Vos at Temperature
Vos(T) = Vos(25°C) + drift × ΔT
Ib for BJT
Ib doubles every ~10°C

Op-Amp Selection Guide

Choose the right op-amp type based on your dominant error source:

If Dominant Error Is... Choose... Example Parts
High source impedance (> 1MΩ) JFET or CMOS TL072, OPA2134, LMC6001
DC accuracy / low drift Chopper OPA333, LTC2057, MAX44250
Low noise (1/f and broadband) BJT OP27, AD797, OPA1612
Low power / battery operation CMOS LMC660, OPA344, TLV2372
Strain gauge / bridge sensor Chopper or precision BJT INA333, AD8551, OPA335
Rule of Thumb: If source impedance > 100kΩ, avoid BJT op-amps. If temperature range is wide (industrial/automotive), prioritize low drift. If DC accuracy < 100µV, consider choppers.
