Comparators and Schmitt Triggers

Comparators convert analog signals to digital by comparing an input to a reference threshold. Schmitt triggers add hysteresis to prevent oscillation on noisy signals.

Basic Comparator
Vout = HIGH if Vin > Vref
Schmitt Trigger
Two thresholds: VTH (rising) and VTL (falling)
Key Insight: Never use an op-amp as a comparator! Op-amps have slow recovery from saturation. Use dedicated comparators (LM311, LM393) for digital outputs.

Comparator vs Op-Amp

Feature Op-Amp (LM741) Comparator (LM311)
Output Analog (rail-to-rail) Digital (open-collector/push-pull)
Recovery from saturation Slow (µs to ms) Fast (ns)
Propagation delay 1-10 µs 100-500 ns
Output drive Low (mA) High (10-50mA)
Common Mistake: Using an op-amp as a comparator causes slow response, potential latch-up, and oscillation. Always use a real comparator for threshold detection.
