Op-Amp Input Bias Current Compensation

Real op-amps require small input currents to bias their input transistors. These bias currents flow through external resistances and create DC offset errors. Understanding and compensating for these effects is crucial for precision circuits.

Understanding Bias Currents

Input Bias Current (IB)

The average of the two input currents:

IB = (IB+ + IB-) / 2

Input Offset Current (IOS)

The difference between the two input currents:

IOS = |IB+ - IB-|

Typical Values by Op-Amp Type

Input Type Example IB (typ) IOS (typ)
Bipolar LM741, NE5532 80-500 nA 20-200 nA
Bias-Compensated Bipolar OP07, OP27 1-4 nA 0.5-2 nA
JFET Input TL072, OPA2134 5-100 pA 1-25 pA
CMOS LMC6482, OPA2340 0.01-1 pA 0.01-0.5 pA

Without Compensation

Problem

The bias current IB- flows through RF, creating an output offset. With R+ = 0Ω at the non-inverting input, IB+ creates no error, but IB- creates an error voltage equal to IB- × RF.

With Compensation

Why This Works

When RCOMP = R1 ∥ RF, both inputs see the same Thevenin resistance. If IB+ = IB-, the voltage drops at both inputs are equal and cancel out. The remaining error is due only to IOS, which is typically 5-10× smaller than IB.

Non-Inverting Amplifier Compensation

For non-inverting amplifiers, place RCOMP in series with the input signal. This matches the impedance seen by the non-inverting input to the parallel combination seen by the inverting input.

Temperature Effects on Bias Current

Bipolar Input Stage

Bias current approximately doubles for every 10°C rise:

IB(T) = IB(25°C) × 2(T-25)/10

JFET and CMOS Inputs

Gate leakage in FET inputs also increases with temperature, doubling roughly every 10°C. However, since the initial values are in picoamps, the absolute error remains much smaller than bipolar inputs across the temperature range.
