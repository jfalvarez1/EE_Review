Instrumentation Amplifiers

Instrumentation amplifiers (In-Amps) are precision differential amplifiers with very high input impedance and excellent CMRR. They're essential for bridge sensor interfaces and low-level signal acquisition.

Three Op-Amp Gain
G = 1 + 2R/RG
Output
Vout = G × (V+ − V−)
Key Insight: Both inputs have very high impedance (buffer stages), so the in-amp doesn't load the sensor. Gain is set by a single resistor RG.

Three Op-Amp Topology

The classic instrumentation amplifier uses three op-amps:

Stage Function Key Benefit
U1, U2 (Input) Buffer + differential gain Very high Zin, single-resistor gain set
U3 (Output) Difference amplifier CMRR, level shift via Vref
Gain Equation Derivation: The voltage across RG equals (V+ - V-). Current through RG flows through both R resistors, creating a differential output from the first stage of (V+ - V-) × (1 + 2R/RG). The difference amplifier then extracts this while rejecting common-mode.

Common Applications

Application Sensor Type Typical Signal Required CMRR
Strain Gauge Wheatstone bridge 1-10 mV/V >100 dB
Load Cell Wheatstone bridge 2 mV/V typical >100 dB
Thermocouple Differential, grounded 40 µV/°C (Type K) >80 dB
ECG/EKG Body electrodes 0.5-4 mV >120 dB (60Hz rejection)

Application: Wheatstone Bridge Interface

The in-amp is ideal for interfacing with bridge sensors (strain gauges, load cells, pressure sensors):

Bridge Output
ΔV = Vexc × (ΔR/R) / 4
Full-Bridge (4 active)
ΔV = Vexc × (ΔR/R)
Bridge Sensitivity: Strain gauge bridges are rated in mV/V (output per volt of excitation). A 2mV/V load cell with 10V excitation produces 20mV full-scale output.
