Systematic Debug Methodology

Random poking wastes time. Learn a systematic approach to debugging that efficiently isolates problems in any electronic system, from simple circuits to complex mixed-signal designs.

Observe
Gather symptoms first
Hypothesize
Form testable theories
Test
Design decisive experiments
Iterate
Refine until solved
The Golden Rule: Never make more than one change at a time. If you change two things and it works, you don't know which fixed it. If it doesn't work, you don't know which broke it more.

Common Debug Patterns

Pattern Indicates Check
Works at first, then fails Thermal issue Temperature, cooling, derating
Works cold, fails when touched Cracked solder joint Visual, flex board, reflow
Fails only under load Power/current limit Voltage drop, current draw
Fails when other circuit active Crosstalk, EMI, ground Isolation, shielding, grounding
Fails at certain times External interference Motors, HVAC, RF sources
Marginal/border-line operation Component tolerance stack Measure actual values, temperature
