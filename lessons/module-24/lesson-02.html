LED Backlight Driver Design

Modern laptop and monitor displays use LED backlighting for thin profiles, low power consumption, and excellent color gamut. The LED driver must provide constant current to strings of series-connected LEDs, typically using a boost converter topology.

What You'll Learn:
  • Why boost topology is needed for LED strings
  • Constant current LED driver design
  • PWM and analog dimming techniques
  • Multi-string current matching
  • Efficiency and thermal considerations

Why Boost Topology for LED Backlighting?

A laptop display typically has multiple strings of 6-10 white LEDs in series. Each LED has a forward voltage of ~3.0-3.3V, so a 7-LED string requires:

V_LED = 7 × 3.2V = 22.4V

Since the laptop runs from a battery (7-17V) or USB-C adapter (5-20V), a boost converter is essential to generate the high voltage needed.

LED Dimming Techniques

Display brightness adjustment requires dimming the LEDs. Two primary methods exist:

1. PWM Dimming (Digital)

2. Analog (DC) Dimming

Hybrid Approach (Best of Both)

Most modern backlight drivers use hybrid dimming:

  • Above ~20%: Use analog dimming (no flicker)
  • Below ~20%: Use PWM dimming at high frequency (wide range)

Multi-String Current Matching

Displays have multiple LED strings for uniform illumination. Due to LED Vf variations, strings need individual current regulation to maintain matching.

Adaptive Boost Output

The boost controller monitors the voltage across current sinks and adjusts VOUT to maintain minimum headroom (typically 0.5-1.5V). This maximizes efficiency by not over-driving the boost when LEDs have lower Vf.

Current Matching Spec: ±1-3% typical between strings. LED drivers like MAX16809, TPS61500, and ISL97684 integrate 4-16 matched current sinks with per-string fault detection.

SPICE Simulation - Boost LED Driver

* Boost Converter LED Backlight Driver
* 7 LEDs per string, 4 strings, 80mA each

.param VIN=12 VLED=3.2 NLEDS=7 ILED=80m NSTR=4

* Calculate output voltage
.param VOUT={NLEDS*VLED+1.5}

* Input supply
VIN vin 0 DC {VIN}

* Boost converter (behavioral model)
* Simplified: just shows current limiting behavior
Lboost vin sw 47u IC=0
Dboost sw vout DSCHOTTKY
.model DSCHOTTKY D(IS=1u RS=20m VJ=0.4 CJO=50p)

* MOSFET switch (PWM controlled)
.param DUTY={1-VIN/VOUT}
Vpwm pwm_in 0 PULSE(0 10 0 1n 1n {DUTY/600k} {1/600k})
Msw sw 0 pwm_gate NMOS_SW
Vgate pwm_gate 0 PWL(0 0)
Bgate pwm_gate 0 V=IF(V(pwm_in)>5, 10, 0)
.model NMOS_SW NMOS(VTO=2 KP=50 RD=20m)

* Output capacitor
Cout vout 0 10u IC={VOUT}

* LED Strings (4 parallel strings of 7 LEDs each)
* Each string modeled as voltage source + current sink
Vled1 vout led1_bot DC {NLEDS*VLED}
Iled1 led1_bot 0 DC {ILED}

Vled2 vout led2_bot DC {NLEDS*VLED}
Iled2 led2_bot 0 DC {ILED}

Vled3 vout led3_bot DC {NLEDS*VLED}
Iled3 led3_bot 0 DC {ILED}

Vled4 vout led4_bot DC {NLEDS*VLED}
Iled4 led4_bot 0 DC {ILED}

.tran 100n 500u 0 100n

.control
run
plot V(vout) title 'Boost Output Voltage'

.endc
.end

LED Backlight Driver Design Checklist

Progressive Exercises

Level 1: Fundamentals

Exercise 1: A laptop display has 8 LEDs per string with Vf = 3.1V each. Including 1.2V headroom, what boost output voltage is needed?

VOUT = (N × Vf) + headroom

Exercise 2: A boost converter operates from 12V input to 26V output. What is the duty cycle?

D = 1 - (VIN/VOUT)

Exercise 3: An LED string draws 60mA at 25.5V. What power does the string consume?

P = V × I

Level 2: Application

Exercise 4: A backlight has 6 strings at 70mA each, 24V output from 8V input. At 85% efficiency, what is the input current?

PIN = POUT/η, then IIN = PIN/VIN

Exercise 5: A boost LED driver at 500kHz needs CCM with 30% ripple. Input is 12V, duty = 50%, average input current = 400mA. What inductor value?

ΔI = 0.3 × Iavg, L = VIN × D / (f × ΔI)

Level 3: System Design

Exercise 6: PWM dimming at 200Hz with 1% duty cycle. What is the ON time per cycle?

Period = 1/f = 5ms, ON time = D × Period

Exercise 7: A 4-string backlight with 80mA/string draws total 320mA from 28V output (8.96W). With 88% efficiency from 12V, what is heat dissipated in the boost driver?

PIN = POUT/η, Heat = PIN - POUT
