Key Formulas

Reflection Coefficient:
    ρ = (ZL - Z0) / (ZL + Z0)

    ρ = 0: Perfect match (no reflection)
    ρ = +1: Open circuit (full positive reflection)
    ρ = -1: Short circuit (full negative reflection)

Propagation Delay (FR4):
    tpd ≈ 6.4 ns/m (microstrip)
    tpd ≈ 7.0 ns/m (stripline)
    Or: tpd = √(εr) / c × length

Critical Length:
    Lcrit = tr / (2 × tpd)

    If trace > Lcrit, termination needed

Crosstalk (NEXT):
    Near-end: Vne ≈ (Cm + Lm/Z0²) × dV/dt × len
    Reduce: spacing, ground plane, shorter parallel run

Eye Opening:
    Vopen = Vhigh - ISI - crosstalk - noise
    Topen = Tbit - jitter - rise/fall time
