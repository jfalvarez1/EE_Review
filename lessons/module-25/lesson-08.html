Introduction

The Nyquist stability criterion is a powerful graphical method for determining closed-loop stability from the open-loop frequency response. Unlike Bode analysis, Nyquist can handle systems with RHP poles (unstable open-loop systems) and provides insight into stability margins in a unified way.

Why Nyquist?

Bode plots work well for most amplifier circuits, but Nyquist analysis is essential when:

  • The open-loop system is unstable (has RHP poles)
  • You need to assess conditional stability
  • Multiple gain crossings occur in the Bode magnitude plot
  • You want a unified view of gain and phase margins

The Nyquist Plot

A Nyquist plot shows the complex value of the loop gain T(jω) as frequency varies from 0 to infinity:

Nyquist Plot Construction

For each frequency ω from 0 to ∞:

  • Calculate T(jω) = |T|∠φ
  • Plot the real part: Re[T] = |T|cos(φ)
  • Plot the imaginary part: Im[T] = |T|sin(φ)

The result is a curve in the complex plane that traces out the loop gain as frequency increases.

The Nyquist Criterion

The Nyquist criterion relates encirclements of the critical point (-1, 0) to closed-loop stability:

Nyquist Stability Criterion

N = P - Z

Where:

  • N = Number of clockwise encirclements of (-1, 0)
  • P = Number of open-loop RHP poles (unstable poles of T(s))
  • Z = Number of closed-loop RHP poles (unstable poles of 1 + T(s))

For Stability

Z = 0 (no closed-loop unstable poles), so:

N = P
  • If P = 0 (stable open-loop): N must be 0 (no encirclements)
  • If P > 0 (unstable open-loop): N must equal P (P counter-clockwise encirclements)

Practical Interpretation

For most amplifier circuits where the open-loop system is stable (P = 0), the Nyquist plot must NOT encircle the point (-1, 0) for closed-loop stability.

Reading Stability Margins from Nyquist

Both phase margin and gain margin can be read directly from the Nyquist plot:

Margins on the Nyquist Plot

Gain Margin: The distance from the origin to where the Nyquist curve crosses the negative real axis, compared to unity:

GM = 1 / |T(jω₁₈₀)|

Where ω₁₈₀ is the frequency where phase = -180°

Phase Margin: The angle from the negative real axis to the point where |T| = 1:

PM = 180° + ∠T(jω_c)

Where ω_c is the gain crossover frequency

Distance to (-1, 0): The minimum distance from the Nyquist curve to the critical point indicates the system's robustness.

Encirclement Counting

Counting encirclements correctly is crucial:

Encirclement Rules

  1. Draw a line from (-1, 0) to any point outside the plot
  2. Count how many times the Nyquist curve crosses this line
  3. Crossings from right to left (as you travel along the curve with increasing ω) count as +1 (clockwise)
  4. Crossings from left to right count as -1 (counter-clockwise)
  5. The net count is N

Conditional Stability

Some systems are "conditionally stable" - they are stable for a range of loop gains but become unstable if gain is increased or decreased too much:

Conditional Stability Warning

A conditionally stable system has the Nyquist curve that:

  • Initially wraps around (-1, 0) in one direction
  • Then wraps back in the opposite direction
  • Net encirclements may be zero, but reducing gain could cause instability!

Design Rule: Avoid conditionally stable designs when possible. They can become unstable during power-up, at low signal levels, or when gain-setting components drift.

Complete Nyquist Contour

For rigorous analysis, we must consider the complete Nyquist contour in the s-plane:

The Nyquist Contour

The contour consists of:

  1. Positive imaginary axis: s = jω, ω from 0⁺ to +∞
  2. Large semicircle: s = Re^(jθ), R → ∞, θ from +90° to -90°
  3. Negative imaginary axis: s = jω, ω from -∞ to 0⁻
  4. Small indentations: Around any poles on the imaginary axis

For most practical systems, we only plot the positive frequency portion and reflect it about the real axis (since T(jω)* = T(-jω) for real systems).

Nyquist for Systems with Integration

Systems with poles at the origin (integrators) require special handling:

Handling Poles at s = 0

For T(s) = K/s × (...), the Nyquist contour must indent around the origin:

  • As ω → 0⁺, |T| → ∞ and phase starts at -90° per integrator
  • The Nyquist plot comes from infinity along a specific direction
  • The indentation maps to a large arc in the T-plane

Worked Example: Three-Pole System

Problem

Analyze stability of a feedback system with T(s) = 1000/(s/100 + 1)(s/1000 + 1)(s/10000 + 1)

Step 1: Identify Open-Loop Poles

Poles at s = -100, -1000, -10000 rad/s (all in LHP)

P = 0 (open-loop stable)

Step 2: Calculate Key Points

At ω = 0: T = 1000∠0°

At ω = 100: T ≈ 707∠-45°

At ω = 1000: T ≈ 100∠-135° (approximately)

At ω → ∞: T → 0∠-270°

Step 3: Find Phase Crossover

Phase = -180° when:

-arctan(ω/100) - arctan(ω/1000) - arctan(ω/10000) = -180°

Solving numerically: ω ≈ 3160 rad/s (503 Hz)

Step 4: Check Magnitude at Phase Crossover

|T(j3160)| = 1000 / √(1+31.6²) / √(1+3.16²) / √(1+0.316²)

= 1000 / (31.6 × 3.32 × 1.05) = 9.1

Since |T| > 1 at -180° phase, the curve passes to the LEFT of (-1, 0)

Step 5: Count Encirclements

The curve encircles (-1, 0) clockwise once → N = 1

With P = 0: Z = P - N = 0 - 1 = -1 (?!)

This is impossible, so we have 1 encirclement → Z = 1 unstable closed-loop pole

Conclusion

The system is UNSTABLE. The Nyquist plot encircles (-1, 0) once, indicating one closed-loop RHP pole.

Gain margin = 1/9.1 = 0.11 = -19 dB (negative, confirming instability)

Comparison: Bode vs Nyquist

Aspect Bode Plot Nyquist Plot
Display Magnitude and phase vs. frequency (two plots) Complex plane (single plot)
Frequency scale Logarithmic Implicit (parametric)
Stability criterion PM > 0 and GM > 1 at crossovers Count encirclements of (-1, 0)
RHP poles (unstable T) Criterion not directly applicable Handles via P term
Multiple crossovers Can be confusing Naturally handled
Design insight Easier for compensation design Better for stability assessment
