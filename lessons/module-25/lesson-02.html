Feedback Topologies

There are four fundamental feedback topologies, classified by how the feedback signal is sampled from the output and mixed with the input. Understanding these topologies is essential for analyzing real circuits.

Razavi's Classification: Feedback topologies are named by the connection at input and output:

  • Series = voltage addition (input terminal)
  • Shunt = current addition (input terminal)
  • Voltage = sample output voltage
  • Current = sample output current

The Four Topologies at a Glance

Topology Input Mix Output Sample Gain Type Zin Zout
Series-Shunt Series (V) Shunt (V) Voltage gain (V/V) ↑ (1+Aβ) ↓ /(1+Aβ)
Shunt-Series Shunt (I) Series (I) Current gain (I/I) ↓ /(1+Aβ) ↑ (1+Aβ)
Series-Series Series (V) Series (I) Transconductance (I/V) ↑ (1+Aβ) ↑ (1+Aβ)
Shunt-Shunt Shunt (I) Shunt (V) Transresistance (V/I) ↓ /(1+Aβ) ↓ /(1+Aβ)

Topology 1: Series-Shunt (Voltage Amplifier)

This is the most common topology - the non-inverting op-amp configuration is a perfect example.

Characteristics

  • Senses output voltage (shunt connection at output)
  • Subtracts feedback voltage from input (series connection at input)
  • Ideal for voltage amplifiers - high Zin, low Zout

Impedance Analysis (Razavi Derivation)

Input Impedance:

With series mixing, the input sees the full loop gain:

Zin,CL = Zin,OL × (1 + Aβ)

Output Impedance:

With shunt (voltage) sampling, the output impedance is reduced:

Zout,CL = Zout,OL / (1 + Aβ)

Physical Interpretation: Feedback "stiffens" the output - any load that tries to change Vout is counteracted by the loop.

Worked Example: Non-Inverting Amplifier

Given: Op-amp with A = 105, Zin,OL = 2MΩ, Zout,OL = 75Ω

Feedback: R1 = 1kΩ, R2 = 9kΩ (gain = 10)

Calculate:

β = R1/(R1+R2) = 1k/10k = 0.1
Aβ = 105 × 0.1 = 104

Zin,CL = 2MΩ × 104 = 20GΩ
Zout,CL = 75Ω / 104 = 7.5mΩ

The feedback has made the amplifier nearly ideal: very high input impedance, nearly zero output impedance!

Topology 2: Shunt-Shunt (Transimpedance Amplifier)

This topology converts input current to output voltage - the classic transimpedance amplifier (TIA).

Characteristics

  • Senses output voltage (shunt connection at output)
  • Subtracts feedback current from input (shunt connection at input)
  • Ideal for current-to-voltage conversion - low Zin, low Zout

Impedance Analysis

Input Impedance:

With shunt mixing, input impedance is reduced (current sensing):

Zin,CL = Zin,OL / (1 + Aβ)

Output Impedance:

Still reduced due to voltage sampling:

Zout,CL = Zout,OL / (1 + Aβ)

Physical Interpretation: The virtual ground at the inverting input makes Zin appear very low to the current source.

Why TIAs Use Shunt-Shunt

A photodiode outputs current. We want:

  • Low input impedance (to absorb all the photocurrent)
  • Low output impedance (to drive following stages)
  • Voltage output proportional to input current

Shunt-shunt feedback naturally provides all three!

Topology 3: Shunt-Series (Current Amplifier)

This topology amplifies current - less common in discrete design but important in IC design.

Characteristics

  • Senses output current (series connection at output - sense resistor)
  • Subtracts feedback current from input (shunt connection at input)
  • Ideal for current amplifiers - low Zin, high Zout

Current Mirror Example

A Wilson current mirror is a shunt-series feedback amplifier:

  • Input current is "shunted" into Q1's collector
  • Output current is sensed in series with Q3's emitter
  • Feedback through Q2 base improves output impedance

AI ≈ 1 (current gain)
Zout = ro × (1 + gmro) ≈ βro

Topology 4: Series-Series (Transconductance Amplifier)

This topology converts input voltage to output current - used in voltage-controlled current sources.

Characteristics

  • Senses output current (series connection at output)
  • Subtracts feedback voltage from input (series connection at input)
  • Ideal for V-to-I converters - high Zin, high Zout

Classic Example: Emitter Degeneration

A common-emitter amplifier with emitter resistor RE:

  • Input voltage is compared to VE = Iout × RE
  • This is series-series feedback!

Gm = Iout/Vin ≈ 1/RE (when gmRE >> 1)
Zin = rπ + (β+1)RE (increased)
Zout = ro(1 + gmRE) (increased)

How to Identify the Topology

Art of Electronics Practical Rule

"Look at how the feedback network connects. If the output wire goes to the feedback network, you're sampling voltage. If a resistor is in series with the output, you're sampling current. Same logic applies at the input."

Identification Algorithm (Razavi Method)

  1. At the output: Is the feedback connected in parallel with the load (shunt/voltage) or in series with the output path (series/current)?
  2. At the input: Is the feedback signal added as a voltage (series) or injected as a current (shunt)?

Loading Effects in Feedback (Advanced)

Real feedback networks load both the amplifier and the source. Razavi's approach accounts for this:

The Complete Analysis Procedure

  1. Identify the feedback network (usually a resistor divider)
  2. Calculate the loading:
    • At input: What impedance does the feedback network present?
    • At output: What load does the feedback network add?
  3. Find the "loaded" open-loop gain A': Include loading effects
  4. Find β from the unloaded feedback network
  5. Apply: ACL = A' / (1 + A'β)

Example: Inverting Amplifier Loading

The feedback network (R1 and R2) loads the op-amp output:

Zload,feedback = R1 + R2

This reduces the effective open-loop gain if the op-amp has significant output impedance.

Summary: Choosing the Right Topology
