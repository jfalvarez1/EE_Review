Introduction

When a feedback system has insufficient phase margin, we must add compensation to stabilize it. Compensation modifies the loop gain frequency response to ensure adequate stability margins. This lesson covers the fundamental compensation techniques used throughout analog design.

The Compensation Problem

Consider an amplifier with two poles at frequencies fp1 and fp2. Each pole contributes -90° of phase shift at high frequencies. If the loop gain is still greater than unity when both poles have taken effect, the phase margin may be dangerously low or even negative (unstable).

Compensation Goal: Modify the frequency response so that the magnitude crosses 0 dB while the phase is still above -180° (with adequate margin).

Dominant Pole Compensation

The simplest compensation technique is to introduce a dominant pole at a frequency much lower than all other poles. This ensures the loop gain drops below unity before the higher-frequency poles contribute significant phase shift.

Dominant Pole Design Rule

To achieve phase margin PM, place the dominant pole fd such that:

funity < fp2 / tan(90° - PM)

For PM = 60°: funity < fp2 / 1.73

For PM = 45°: funity < fp2

Implementation Methods

  • External Capacitor: Add a capacitor at a high-impedance node to create a low-frequency pole
  • Miller Capacitor: Use feedback capacitance to create effective large capacitance (see Lesson 5)
  • Integration: Some amplifiers are designed with intentionally low bandwidth (integrator-like response)

Don't Do This: Random Capacitor Placement

Adding capacitors at arbitrary nodes can create additional poles and make stability worse! Always analyze the impedance at potential compensation nodes before adding capacitance.

Lead Compensation

Lead compensation adds a zero-pole pair where the zero occurs before the pole. This provides phase boost (positive phase shift) near the crossover frequency, improving phase margin without reducing bandwidth as much as dominant pole compensation.

Lead Compensator Transfer Function

H(s) = (1 + s/ωz) / (1 + s/ωp), where ωz < ωp

Maximum phase boost: φmax = arctan((ωp - ωz) / (2√(ωzωp)))

Occurs at geometric mean: ωmax = √(ωzωp)

Circuit Implementation

A common lead compensation network uses a resistor-capacitor combination:

Transfer function: H(s) = (R1 + R2) / R2 × (1 + sR1C) / (1 + s(R1||R2)C)

  • Zero at: fz = 1/(2πR1C)
  • Pole at: fp = 1/(2π(R1||R2)C) = (1 + R1/R2)/(2πR1C)

Razavi Design Insight

Place the geometric mean of the zero and pole at the desired crossover frequency. This positions maximum phase boost exactly where it's needed.

Lag Compensation

Lag compensation adds a pole-zero pair where the pole occurs before the zero. This reduces loop gain at high frequencies while adding minimal phase lag at the crossover frequency (if designed properly).

Lag Compensator Transfer Function

H(s) = (1 + s/ωp) / (1 + s/ωz), where ωp < ωz

Key: Both pole and zero should be at least a decade below crossover to minimize phase impact at crossover.

When to Use Lag Compensation

  • When you need to reduce DC gain error but can accept bandwidth reduction
  • When lead compensation alone doesn't provide enough phase margin
  • In combination with lead for "lead-lag" compensation

Lead-Lag (PID-like) Compensation

For challenging systems, combining lead and lag creates a more powerful compensator. This is similar to PID control theory applied to analog circuits.

Lead-Lag Compensator

Combines the benefits of both:

  • Lag portion: Increases low-frequency gain (reduces DC error)
  • Lead portion: Adds phase boost at crossover for stability

Worked Example: Lead Compensator Design

Problem

An amplifier has loop gain T(s) = 10000/(1 + s/ω1)(1 + s/ω2) where f1 = 100 Hz and f2 = 10 kHz. Design a lead compensator to achieve 60° phase margin.

Step 1: Analyze Uncompensated System

DC loop gain: 20log(10000) = 80 dB

With two poles, the system rolls off at -40 dB/decade after both poles.

Uncompensated crossover: Using |T(jω)| = 1:

At high frequencies: |T| ≈ 10000/(ω/ω1)(ω/ω2) = 10000·ω1·ω2/ω²

Setting |T| = 1: ωc = √(10000 × 628 × 62832) = 62.8 krad/s → fc ≈ 10 kHz

Phase at crossover: -arctan(10k/100) - arctan(10k/10k) = -89.4° - 45° = -134.4°

Phase margin: 180° - 134.4° = 45.6° (insufficient for 60° target)

Step 2: Determine Required Phase Boost

Need: 60° - 45.6° = 14.4° additional phase margin

Add ~20° margin for safety: Design for 35° phase boost

Step 3: Design Lead Compensator

Maximum phase boost formula: φmax = arcsin((α-1)/(α+1)) where α = ωp/ωz

For 35° boost: sin(35°) = (α-1)/(α+1) → α = (1 + 0.574)/(1 - 0.574) = 3.69

Place geometric mean at crossover: √(fz·fp) = 10 kHz

With α = 3.69: fz = 10k/√3.69 = 5.2 kHz, fp = 10k × √3.69 = 19.2 kHz

Step 4: Verify

Lead network adds: +arctan(10k/5.2k) - arctan(10k/19.2k) = 62.5° - 27.5° = 35° ✓

New phase margin: 45.6° + 35° = 80.6° (exceeds 60° target with margin)

Step 5: Component Values

Choose C = 1 nF for practical values:

R1 = 1/(2π × 5.2k × 1n) = 30.6 kΩ → use 30 kΩ

R2 = R1/(α-1) = 30k/2.69 = 11.2 kΩ → use 11 kΩ

Final Design

R1 = 30 kΩ, R2 = 11 kΩ, C = 1 nF

Zero at 5.3 kHz, Pole at 19.5 kHz

Phase margin improved from 46° to ~78°

Dominant Pole Significantly reduces Improves (by lowering crossover) Bandwidth not critical, simple implementation needed
Lead Can maintain or increase Improves (phase boost) Need phase margin without sacrificing bandwidth
Lag Reduces somewhat Minimal effect if designed properly Need higher DC gain, can accept lower bandwidth
Lead-Lag Maintains reasonably Improves significantly Challenging systems, need both DC accuracy and stability

Common Mistakes in Compensation

Art of Electronics Wisdom

  1. Compensating at the wrong node: Adding capacitance at a low-impedance node has minimal effect. Always check node impedance first.
  2. Creating new poles: The compensation capacitor interacts with circuit impedances to create new poles. Verify you haven't added a pole near crossover.
  3. Ignoring parasitic poles: Real circuits have many high-frequency poles. Simulation is essential for verification.
  4. Over-compensating: Too much compensation wastes bandwidth. Aim for adequate margin (45-60°), not maximum.
