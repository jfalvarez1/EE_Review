Based on power electronics control theory and Venable/Middlebrook analysis methods

Introduction

Switching power supplies (buck, boost, flyback, etc.) are feedback systems that must maintain stable output voltage despite load and line variations. However, the small-signal dynamics of switching converters are complex, with poles and zeros that depend on operating point, component values, and control mode. This lesson covers the essentials of power supply loop stability.

Why Power Supplies Need Special Treatment

Unlike linear amplifiers, switching converters have:

  • Right-half-plane zeros: Boost and flyback converters have RHP zeros that limit bandwidth
  • LC resonance: The output filter creates a double pole with potential 180° phase shift
  • ESR zeros: Output capacitor ESR creates zeros that can help or hurt stability
  • Operating point dependence: Pole/zero locations vary with duty cycle and load

Voltage-Mode Control Loop

In voltage-mode control, the error amplifier directly controls the duty cycle through a PWM comparator:

Buck Converter Transfer Function (Voltage Mode)

Control-to-Output Transfer Function

For a buck converter with LC output filter:

Gvd(s) = Vin × HLC(s)

Where the LC filter transfer function is:

HLC(s) = (1 + s/ωz,ESR) / [1 + s/(Q×ω0) + s²/ω0²]

Key Frequencies

  • LC resonance: f0 = 1/(2π√(LC))
  • ESR zero: fz,ESR = 1/(2πRESRC)
  • Q factor: Q = Rload√(C/L) (can be very high!)

The LC Double-Pole Problem

At the LC resonance frequency:

  • The gain peaks by a factor of Q (Q can be 10-100!)
  • Phase drops by 180° very quickly
  • Without proper compensation, this creates severe instability

Type II and Type III Compensators

To stabilize voltage-mode converters, we use Type II or Type III compensators that add poles and zeros to shape the loop gain:

Type II Compensator

Type II Transfer Function

H(s) = (ωz/ωp) × (1 + s/ωz) / [(s/ωi)(1 + s/ωp)]

Features:

  • One zero to boost phase
  • One high-frequency pole to filter switching noise
  • Origin pole (integrator) for zero DC error
  • Maximum phase boost: 90° (not enough for LC double pole!)

Type III Compensator

Type III Transfer Function

H(s) = K × (1 + s/ωz1)(1 + s/ωz2) / [(s/ωi)(1 + s/ωp1)(1 + s/ωp2)]

Features:

  • Two zeros to provide up to 180° phase boost
  • Two high-frequency poles
  • Origin pole for zero DC error
  • Can compensate the LC double pole!

Design Procedure (Voltage Mode)

Type III Compensator Design Steps

Step 1: Determine Crossover Frequency

Rule of thumb: fc = fsw/10 to fsw/5

Also limited by RHP zero if present (boost/flyback)

Step 2: Place Zeros at LC Resonance

fz1 = fz2 = f0 = 1/(2π√LC)

This cancels the -180° phase shift from the LC double pole

Step 3: Place Poles at High Frequency

fp1 = fz,ESR (cancel ESR zero if it causes gain peaking)

fp2 = fsw/2 (filter switching noise)

Step 4: Set Gain for Desired Crossover

Adjust K so loop gain equals 0 dB at fc

Current-Mode Control

Current-mode control uses inner current loop feedback, which dramatically improves the power stage dynamics:

Current Mode Advantages

  • Eliminates LC double pole: The inductor becomes a controlled current source
  • Simpler compensation: Type II compensator often sufficient
  • Inherent current limiting: Current is directly controlled
  • Better line rejection: Input voltage changes are rejected by inner loop

Current-Mode Control-to-Output

With current-mode control, the power stage looks like:

Gvc(s) ≈ Rload × (1 + s/ωz,ESR) / (1 + sRloadC)

This is a single-pole system! The inductor pole is removed by the current loop.

Right-Half-Plane Zero (Boost and Flyback)

Boost, buck-boost, and flyback converters have a fundamental bandwidth limitation: the right-half-plane zero.

RHP Zero Location

For boost converter:

fRHP = Rload(1-D)² / (2πL)

Where D = 1 - Vin/Vout

The RHP zero:

  • Adds phase lag like a pole
  • But increases gain like a zero
  • Cannot be compensated! Crossover must be well below fRHP

Design Rule for RHP Zero

Loop crossover frequency must satisfy:

fc < fRHP / 5

This fundamentally limits boost converter bandwidth, especially at high duty cycle (high boost ratio).

Measuring Loop Gain

Loop gain can be measured using voltage injection:

Bode Plot Measurement

  1. Inject small AC signal into feedback loop
  2. Measure voltage before and after injection point
  3. Loop gain = Vreturn / Vinject
  4. Sweep frequency and plot magnitude/phase

Use a network analyzer or frequency response analyzer for accurate measurements.

Worked Example: Buck Converter Compensation

Specifications

  • Vin = 12V, Vout = 5V
  • fsw = 500 kHz
  • L = 4.7 μH, C = 100 μF (ceramic, ESR = 5 mΩ)
  • Target crossover: 50 kHz, Phase margin: 60°

Step 1: Calculate Power Stage Characteristics

LC resonance: f0 = 1/(2π√(4.7μ × 100μ)) = 7.3 kHz

ESR zero: fESR = 1/(2π × 5mΩ × 100μF) = 318 kHz

Note: Ceramic capacitors have very low ESR, so ESR zero is very high

Step 2: Choose Compensator Type

Voltage mode control → Need Type III to handle LC double pole

Current mode → Type II would suffice (single output pole)

We'll design Type III for voltage mode:

Step 3: Place Compensator Zeros

Place both zeros at f0 to cancel LC double pole:

fz1 = fz2 = 7.3 kHz

Step 4: Place Compensator Poles

First pole to cancel ESR zero (if needed) or at crossover: fp1 = 50 kHz

Second pole at half switching frequency: fp2 = 250 kHz

Step 5: Calculate Component Values

Using standard Type III compensator topology:

  • Choose C1 = 1 nF (starting point)
  • R2 = 1/(2π × fz1 × C1) = 1/(2π × 7.3k × 1n) = 21.8 kΩ → use 22 kΩ
  • C2 = 1/(2π × R2 × fp1) = 1/(2π × 22k × 50k) = 145 pF → use 150 pF
  • R3 calculated for desired gain at crossover
  • C3 = 1/(2π × R3 × fz2)

Design Summary

fz1, fz27.3 kHz (at LC resonance)
fp150 kHz (at crossover)
fp2250 kHz (fsw/2)
Crossover50 kHz (fsw/10)
Phase Margin~60° (verify in simulation)

Common Stability Issues

Symptom Likely Cause Solution
Output oscillation at f0 LC resonance not damped Add zeros at f0, verify compensator
Oscillation at fsw/2 Subharmonic oscillation (current mode) Add slope compensation
Slow transient response Crossover too low Increase bandwidth (check RHP zero limit)
Ringing on load step Insufficient phase margin Reduce crossover or improve compensation
Instability at light load Output pole moves to higher frequency Add minimum load or modify compensation
