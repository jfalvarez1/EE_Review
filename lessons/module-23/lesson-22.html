PLL & Clock Generation

Phase-Locked Loops (PLLs) are essential for frequency synthesis, clock multiplication, and jitter cleaning in modern electronics. From generating processor clocks to synthesizing RF carriers, PLLs are everywhere. This lesson covers PLL fundamentals, loop filter design, and practical clock distribution considerations.

Industry Applications

  • Clock Synthesis - CPU, FPGA, SerDes clocking
  • Frequency Synthesis - RF transceivers, software-defined radio
  • Clock Recovery - CDR in high-speed serial links
  • Motor Control - Resolver/encoder signal processing
  • Data Converters - Low-jitter sampling clocks for ADCs

1. PLL Architecture

A PLL is a feedback system that locks an oscillator to a reference frequency:

Key PLL Components

Block Function Key Parameter
Phase Detector (PD) Compares reference and feedback phase Gain KPD (V/rad or A/rad)
Charge Pump (CP) Converts PD output to current pulses ICP (typically 0.1-5 mA)
Loop Filter (LPF) Filters CP output, sets loop dynamics Bandwidth, phase margin
VCO Voltage-controlled oscillator KVCO (Hz/V or rad/s/V)
Divider Divides VCO output by N N (integer or fractional)

Basic PLL Equations

Output Frequency: \( F_{out} = N \times F_{ref} \)

Phase Detector Comparison Frequency: \( F_{PD} = F_{ref} = \frac{F_{out}}{N} \)

Open Loop Gain: \( G(s) = \frac{K_{PD} \cdot K_{VCO}}{N} \cdot Z(s) \)

Where Z(s) is the loop filter transfer function

2. Phase Detector Types

Type I: XOR/Analog Phase Detector

  • Simple XOR gate or analog multiplier
  • Locks at 90° phase offset
  • Limited capture range
  • Used in simple clock recovery

Type II: Phase-Frequency Detector (PFD)

  • Detects both phase and frequency error
  • Wide capture range (can lock from any initial frequency)
  • Outputs UP/DOWN pulses to charge pump
  • Most common in modern PLLs

Dead Zone Problem

If UP and DOWN pulses are too short, the charge pump may not respond (dead zone). This causes increased jitter near lock. Solutions:

  • Add programmable delay to ensure minimum pulse width
  • Use "anti-backlash" PFD architecture
  • Modern PLL ICs have this built-in

3. Loop Filter Design

The loop filter determines PLL bandwidth, phase margin, and lock time. Most PLLs use a 2nd or 3rd order loop filter.

2nd Order (Type 2) Loop Filter

Loop Filter Transfer Function

\[ Z(s) = \frac{1 + sR_1C_1}{s(C_1 + C_2)(1 + sR_1\frac{C_1C_2}{C_1+C_2})} \]

Design Equations

Loop Bandwidth: \( \omega_{BW} = \frac{K_{PD} \cdot K_{VCO}}{N} \cdot \frac{R_1C_1}{C_1 + C_2} \)

Phase Margin: Typically design for 45° - 60°

Zero: \( \omega_z = \frac{1}{R_1 C_1} \) (place below crossover for phase boost)

Pole: \( \omega_p = \frac{C_1 + C_2}{R_1 C_1 C_2} \) (filters high-frequency noise)

4. Jitter and Phase Noise

Clock quality is measured by phase noise (frequency domain) and jitter (time domain):

Phase Noise

  • Measured in dBc/Hz at offset from carrier
  • Specification: L(f) at offset frequency
  • Example: -110 dBc/Hz @ 10kHz offset
  • Dominated by VCO noise at high offsets

Jitter

  • Time-domain variation of clock edges
  • RMS jitter (ps or fs)
  • Peak-to-peak jitter (deterministic component)
  • Integrated over bandwidth of interest

Jitter-Phase Noise Relationship

RMS jitter from integrated phase noise:

\[ \sigma_t = \frac{1}{2\pi f_0} \sqrt{2 \int_{f_1}^{f_2} L(f) df} \]

Where f0 = carrier frequency, L(f) = phase noise in linear units

Approximate Conversion

For flat phase noise L0 over bandwidth B:

\[ \sigma_t \approx \frac{1}{2\pi f_0} \sqrt{2 L_0 \cdot B} \]

Jitter Budget Example

Source Jitter Contribution Notes
Reference oscillator 0.5 ps RMS High-quality TCXO
PLL in-band noise 1.0 ps RMS Dominated by PFD/CP noise
VCO out-of-band 0.8 ps RMS Filtered by loop bandwidth
Output buffer 0.3 ps RMS Added by clock distribution
Total (RSS) 1.4 ps RMS Root-sum-squares

5. Fractional-N PLLs

Integer-N PLLs are limited to output frequencies that are integer multiples of the reference. Fractional-N PLLs overcome this limitation:

Fractional-N Output

\[ F_{out} = \left(N + \frac{F}{M}\right) \times F_{ref} \]

Where N = integer divider, F = fractional numerator, M = modulus

Example: N=10, F=1, M=4 → Division ratio = 10.25

Delta-Sigma Modulation

Modern fractional-N PLLs use delta-sigma (ΔΣ) modulation to shape quantization noise:

  • Instantaneous divide value toggles between N and N+1
  • ΔΣ modulator pushes noise to high frequencies
  • Loop filter attenuates high-frequency noise
  • Results in low in-band spurs

Fractional-N Advantages

  • Higher comparison frequency → lower in-band noise
  • Faster lock time
  • Fine frequency resolution without narrow loop bandwidth
  • Lower reference spurs (higher Fref = farther from carrier)

6. Clock Distribution

Clock Tree Considerations

  • Fanout buffers: LVDS, LVPECL, HCSL for high-speed
  • Skew matching: Equal trace lengths to all destinations
  • Termination: Match to trace impedance (50Ω or 100Ω diff)
  • Decoupling: Local bypass at each buffer
  • Jitter additive: Each buffer adds ~50-200fs jitter

Common Clock Standards

Standard Signaling Amplitude Speed Application
LVDS Differential 350mV Up to 3 Gbps FPGA, SerDes
LVPECL Differential 800mV Up to 5 Gbps Telecom, networking
HCSL Differential 400mV Up to 200 MHz PCIe, DDR
LVCMOS Single-ended 3.3V/1.8V Up to 200 MHz General purpose

7. PLL Design Checklist

Specifications

  • ☐ Output frequency and tuning range
  • ☐ Reference frequency
  • ☐ Phase noise / jitter requirements
  • ☐ Lock time requirement
  • ☐ Spur requirements (reference spurs, fractional spurs)

Loop Design

  • ☐ Choose loop bandwidth (typically Fref/10 to Fref/50)
  • ☐ Design for adequate phase margin (45-60°)
  • ☐ Calculate loop filter components
  • ☐ Verify VCO tuning range covers all operating frequencies
  • ☐ Check lock time meets requirements

Layout

  • ☐ Separate analog/digital grounds (tie at one point)
  • ☐ Shield VCO from digital noise
  • ☐ Keep loop filter close to PLL IC
  • ☐ Use ground plane under VCO and loop filter
  • ☐ Proper decoupling on all supply pins
