Laptop Power Architecture

A modern laptop requires 10-15 different voltage rails to power its various subsystems. Understanding how these rails are generated, sequenced, and managed is essential for embedded systems and power electronics design.

Power Sequencing Requirements

Modern processors and FPGAs have strict power sequencing requirements. Turning rails on/off in the wrong order can cause:

  • Latch-up: Parasitic SCR triggering → device destruction
  • Excessive current draw: ESD protection diodes conduct
  • Data corruption: Flash/EEPROM writes during brownout
  • Unreliable startup: POR (Power-On Reset) not triggered properly

Soft-Start and Inrush Current Limiting

Without soft-start, a buck converter tries to charge its output capacitor instantly, causing massive inrush current that can:

  • Trip upstream protection (fuses, current limiters)
  • Cause input voltage sag affecting other rails
  • Stress input capacitors beyond ratings
  • Generate EMI from high di/dt

SPICE Simulation - Multi-Rail Startup Sequence

Power Sequencing Simulation

* Multi-Rail Power Sequencing Simulation
* Demonstrates PGOOD-based daisy chain startup

.param VIN=12

* Input supply with soft-start
VIN vin 0 PULSE(0 {VIN} 1m 1m 0 100m 200m)

* 3.3V Rail - Stage 1 (first to start)
* Simplified buck model with enable and PGOOD
Xbuck1 vin 0 v3p3 en1 pg1 buck_model VOUT=3.3 TSS=2m TPGD=0.5m
Ven1 en1 0 PWL(0 0 1m 0 1.1m 5)  ; Enable at startup

* 1.8V Rail - Stage 2 (waits for 3.3V PGOOD)
Xbuck2 vin 0 v1p8 pg1 pg2 buck_model VOUT=1.8 TSS=1.5m TPGD=0.5m

* 1.2V Rail - Stage 3 (waits for 1.8V PGOOD)
Xbuck3 vin 0 v1p2 pg2 pg3 buck_model VOUT=1.2 TSS=1m TPGD=0.5m

* CPU Core - Stage 4 (waits for 1.2V PGOOD)
Xvcore vin 0 vcore pg3 pg4 buck_model VOUT=1.0 TSS=2m TPGD=0.5m

* RESET signal - released after VCORE stable
Vrst_ctrl rst_ctrl 0 PWL(0 0 10m 0 10.1m 3.3)
Srst rst_out 0 pg4 0 SW_RST
.model SW_RST SW(VT=2.5 VH=0.1 RON=10 ROFF=1MEG)

* Load models
RL1 v3p3 0 10       ; 330mA load on 3.3V
RL2 v1p8 0 3.6      ; 500mA load on 1.8V
RL3 v1p2 0 1.2      ; 1A load on 1.2V
RLcore vcore 0 0.05 ; 20A load on VCore

* Buck converter subcircuit (behavioral model)
.SUBCKT buck_model vin gnd vout en pgood VOUT=3.3 TSS=2m TPGD=0.5m
* Enable threshold
Bcmp enablecomp 0 V= V(en) > 2 ? 1 : 0
* Soft-start ramp
Css ss gnd 100n IC=0
Gss gnd ss VALUE={IF(V(enablecomp)>0.5, 10u, 0)}
* Output voltage (tracks soft-start, then regulates)
Evout vout_int gnd VALUE={MIN(V(ss)*{VOUT}/0.8, {VOUT})}
Rout vout_int vout 0.1
Cout vout gnd 100u IC=0
* PGOOD (goes high when output > 90% of target)
Bpgood pgood gnd V= DELAY(V(vout)>0.9*{VOUT} ? 3.3 : 0, {TPGD})
.ENDS

.tran 100u 25m 0 10u
.control
run
plot v(v3p3) v(v1p8) v(v1p2) v(vcore) title 'Power Rail Startup Sequence'
plot v(pg1) v(pg2) v(pg3) v(pg4) v(rst_out) title 'PGOOD and RESET Signals'
.endc
.end

Power System Design Checklist

Progressive Exercises

Level 1: Fundamentals

Exercise 1: A laptop requires 3.3V, 1.8V, 1.2V, and 0.9V rails. If generated in cascade from 12V with each stage at 90% efficiency, what is the overall efficiency to the 0.9V rail?

Multiply: 0.90 × 0.90 × 0.90 × 0.90 = ?

Exercise 2: A buck converter has CSS = 47nF and ISS = 5µA charging to VREF = 0.6V. What is the soft-start time?

tSS = CSS × VREF / ISS

Exercise 3: A regulator dissipates 2W in a QFN package with θJA = 40°C/W. If ambient is 50°C, what is the junction temperature?

TJ = TAMB + PDISS × θJA

Level 2: Application

Exercise 4: A 6-phase VRM delivers 90A at 1.0V to a CPU. If each phase runs at D=8.3% with L=200nH and fsw=500kHz from 12V, what is the per-phase inductor current ripple?

ΔI = (VIN - VOUT) × D / (L × fsw)

Exercise 5: You need a 5ms delay between PGOOD and enabling the next stage. If using RC delay on EN pin with R=100kΩ, what capacitor is needed (assuming VTH = 0.63×VCC)?

For RC, V(t) = VCC(1-e^(-t/RC)). At t=τ, V=0.63VCC. So τ=RC=5ms.

Exercise 6: A power path controller switches between 20V adapter and 14.8V (4S) battery. If system load is 45W and charger efficiency is 92%, what is input current from adapter when charging at 30W?

Total input power = (45 + 30/0.92). Then IIN = PIN/20V

Level 3: Design Analysis

Exercise 7: An ultrabook has these loads: 3.3V@2A, 1.8V@1.5A, 1.2V@3A, VCore@25A@0.9V. Calculate total power consumption.

Sum P = V×I for each rail

Exercise 8: For the ultrabook above, if average efficiency from 19V input is 88%, what is heat dissipated by all regulators combined?

PIN = PLOAD/η. Heat = PIN - PLOAD

Exercise 9: A VRM must transition from 0.9V to 1.2V in 10µs for a DVFS event. If output capacitance is 500µF, what average current must the VRM provide during the transition (ignoring load current)?

I = C × dV/dt = 500µF × (0.3V / 10µs)

Level 4: System Integration

Exercise 10: Design question: You're designing a power system with 4 rails. The processor requires 3.3V before 1.8V (>2ms gap), 1.8V before 1.2V (>1ms gap), and VCore last (>5ms after 1.2V). If each stage has 3ms soft-start plus 1ms PGOOD delay, what is minimum time from power-on to VCore stable?

3.3V: 4ms, then wait 2ms, 1.8V: 4ms, wait 1ms, 1.2V: 4ms, wait 5ms, VCore... wait, re-check the sequence!
