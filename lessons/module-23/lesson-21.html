RS-485/CAN Bus Physical Layer

RS-485 and CAN are the backbone of industrial communication. Understanding their physical layer design is essential for building robust, noise-immune interfaces that work reliably in harsh environments. This lesson covers the electrical fundamentals, component selection, and practical design considerations for both standards.

Industry Applications

  • RS-485 - Modbus RTU, PROFIBUS, DMX512 lighting, industrial sensors
  • CAN - Automotive networks, J1939, CANopen, industrial machinery
  • Building Automation - BACnet MS/TP, DALI lighting
  • Process Control - HART, Foundation Fieldbus physical layer
  • Robotics - Motor drives, sensor fusion

1. RS-485 Fundamentals

Differential Signaling

RS-485 uses balanced differential signaling, where information is encoded as the voltage difference between two wires (A and B), not referenced to ground:

2. RS-485 Termination and Biasing

Termination

Proper termination prevents signal reflections that cause bit errors:

Termination Resistor Value

\[ R_T = Z_0 \approx 100-120\Omega \text{ (typical twisted pair)} \]

Use termination at both ends of the bus only. Mid-bus nodes should NOT have termination.

Failsafe Bias Resistors

To ensure the bus stays in MARK (idle) state when no driver is active:

\[ R_{bias} = 500-1000\Omega \]

Pull B to Vcc, pull A to GND. This creates V(B-A) > 200mV when bus is floating.

Failsafe Considerations

  • Many modern transceivers have internal failsafe biasing
  • External bias needed if using older transceivers or long cables
  • Bias resistors slightly load the bus - account in driver loading
  • Open, shorted, or terminated (but un-driven) bus must stay in idle state

3. CAN Bus Physical Layer

CAN Signaling

CAN uses a dominant/recessive signaling scheme:

CAN Electrical Specifications (ISO 11898-2)

Parameter Dominant Recessive Notes
CAN_H Voltage 2.75 - 4.5V 2.0 - 3.0V Nominal 3.5V / 2.5V
CAN_L Voltage 0.5 - 2.25V 2.0 - 3.0V Nominal 1.5V / 2.5V
Differential (H-L) 1.5 - 3.0V -0.5 to 0.05V Threshold at 0.9V / 0.5V
Bus Impedance 120Ω (nom) Termination at each end
Data Rate Up to 1 Mbps CAN FD: up to 8 Mbps
Bus Length 40m @ 1Mbps, 1000m @ 50kbps Inversely related to speed

Dominant Wins!

CAN's arbitration depends on the "wired-AND" behavior:

  • If ANY node drives dominant (0), the bus is dominant
  • Bus is recessive (1) only if ALL nodes are recessive
  • This enables non-destructive bitwise arbitration
  • Lower message IDs have higher priority (more leading zeros)

Transceiver Selection Criteria

  • Data rate: Match to protocol requirements (Modbus typically 9600-115200 baud)
  • ESD protection: Higher is better, especially for exposed connectors
  • Isolation: Required if grounds may differ by > a few volts
  • Fault protection: ±12V for RS-485, ±58V for automotive CAN
  • Failsafe: Internal bias for open/shorted bus conditions
  • Supply voltage: 3.3V or 5V logic compatible

5. Protection Circuits

ESD and Surge Protection

Protection Component Selection

Component Purpose Typical Value Example Part
TVS Diode Array ESD and surge clamping Vclamp < 30V @ 8kV PESD1CAN, SM712
Series Resistor Current limiting during surge 10-100Ω Standard 0603
Common-Mode Choke EMI filtering 50-100Ω @ 100MHz ACM2012
PTC Fuse Overcurrent protection 100-500mA hold MF-FSMF series

Protection Placement Rules

  • TVS as close to connector as possible (before anything else)
  • Series resistors after TVS to limit current into transceiver
  • Ground TVS to chassis ground if isolated
  • Don't forget ground wire protection (TVS to GND)

6. Isolation Design

Isolation is required when ground potentials may differ significantly between nodes:

When to Use Isolation

  • Industrial environments with motor drives
  • Long cable runs (>30m)
  • Different power sources per node
  • Safety requirements (galvanic separation)
  • Mixed voltage systems

Isolation Options

  • Integrated: ADM2587E, ISO1042 (easiest)
  • Discrete: Digital isolator + isolated DC-DC
  • Optocoupler: Legacy, slower, requires external power

Isolation Voltage Rating

Choose isolation rating based on:

  • Working voltage: Max continuous voltage across barrier (e.g., 250Vrms)
  • Withstand voltage: Short-term rating for testing (e.g., 2.5kVrms for 1 min)
  • Surge voltage: Transient capability (e.g., 4kV)

For industrial RS-485: 2.5kV isolation typical. For medical: may require 4kV+.

7. Common Problems and Debugging

RS-485 Issues

Symptom Possible Cause Solution
Intermittent data errors Missing or wrong termination Add 120Ω at both ends only
Garbage characters on idle No failsafe bias Add pull-up on B, pull-down on A
First byte corrupted Turnaround time too short Increase delay after TX disable
Works at short distance, fails at long Ground offset exceeds CMR Add ground wire or use isolation
High bit error rate Stub lengths too long Keep stubs < 30cm at 115200 baud

CAN Issues

Symptom Possible Cause Solution
No communication Wrong bit rate Verify all nodes at same rate
Intermittent errors Missing termination 120Ω at each end of bus
Error frames, no data CAN_H/CAN_L swapped Check wiring polarity
Bus-off errors Severe EMI or wiring issue Improve shielding, check grounds
Dominant timeout Stuck driver or short Check for shorted nodes

Debugging Tools

  • Oscilloscope: Check differential waveform (should see clear transitions)
  • Protocol analyzer: Decode CAN/RS-485 frames
  • Termination check: Measure resistance between A-B with power off (should be ~60Ω for 2×120Ω)
  • Ground offset: Measure voltage between local GND and remote GND

8. Design Checklist

RS-485 Design

  • ☐ Termination (120Ω) at both ends of bus
  • ☐ Failsafe bias if bus may be idle/open
  • ☐ ESD protection at connector
  • ☐ Ground wire included (but not for signal)
  • ☐ Transceiver supports required data rate
  • ☐ Isolation if ground offset > 5V possible
  • ☐ Stub lengths minimized

CAN Design

  • ☐ Termination (120Ω) at both ends of bus
  • ☐ ESD protection (TVS diode)
  • ☐ Common-mode choke for EMI
  • ☐ Transceiver matches speed (CAN 2.0 or FD)
  • ☐ Split termination for CM noise rejection if needed
  • ☐ Proper bus topology (linear, not star)

Cabling

  • ☐ Twisted pair cable (120Ω characteristic impedance)
  • ☐ Shielded cable for noisy environments
  • ☐ Shield grounded at one end only (to prevent ground loops)
  • ☐ Cable length within specification for data rate
