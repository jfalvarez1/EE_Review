Case Study: Battery-Powered IoT Sensor Node

Design an ultra-low-power wireless sensor node for environmental monitoring. This scenario covers power budgeting, sleep modes, energy harvesting considerations, and achieving multi-year battery life.

Key Insight: With a 5-year target and 3000mAh battery, average current must be <68µA. Since TX can draw 15mA for 100ms, sleep current must be extremely low. Every µA counts!

The Scenario

Requirement: Design power system for LoRa environmental sensor.

  • Sensors: Temperature, humidity, light (I2C)
  • MCU: ARM Cortex-M0+ with 1µA sleep
  • Radio: LoRa, 15mA TX, 100ms per transmission
  • Operating range: -20°C to +60°C
  • Report interval: 1 hour (configurable)
  • Battery: 2× AA Lithium (3.6V nominal)
