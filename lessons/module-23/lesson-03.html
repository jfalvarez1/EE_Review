USB-C Power Delivery System Design

USB Type-C with Power Delivery (USB PD) has become the universal standard for device charging, supporting up to 240W (USB PD 3.1 EPR). This lesson covers the complete analog design from connector to power conversion.

Industry Reference: Based on Analog Devices USB-C PD Guide, MAX77958 Datasheet, and LT8253 Buck-Boost Controller.

System Architecture: USB-C PD Sink (Device Side)

Section 1: CC Pin Detection and Cable Orientation

The Configuration Channel (CC) pins serve multiple functions: cable orientation detection, current capability advertisement, and USB PD communication.

CC Pull-Down Resistors (Sink Device)

Resistor Value (Rd) Meaning Max Current Allowed
5.1kΩ to GND Standard USB sink Up to 3A (after negotiation)
1kΩ to GND Audio adapter accessory 500mA
Critical: Both CC1 and CC2 pins must have 5.1kΩ ±10% pull-down resistors for proper sink detection. The source detects which CC line is connected to determine cable orientation.

Section 2: PD Negotiation and VBUS Control

USB PD uses BMC (Biphase Mark Coding) on the CC line to negotiate power contracts. The source advertises capabilities, and the sink requests a specific voltage/current.

PD Message Flow

Power Data Objects (PDOs)

PDO Type Voltage Current Use Case
Fixed 5/9/15/20V Up to 5A Standard charging
PPS (APDO) 3.3-21V variable Up to 5A Fast charging protocols
AVS (EPR) 15-48V adjustable Up to 5A High-power devices

Section 3: Buck-Boost Charger Design

Since USB PD can provide 5-20V (or higher with EPR) while batteries are typically 3-4.4V (1S) or 7-17V (2S-4S), a buck-boost converter is often needed.

Section 4: Protection and Safety

Required Protection Elements

Protection Implementation Typical Threshold
Overvoltage (OVP) TVS + OVP IC (BQ24314) 22-25V for SPR, 55V for EPR
Overcurrent (OCP) In charger IC 125% of max negotiated
Reverse Voltage Ideal diode controller Block if VBUS < VBAT

ESD TVS on CC, D+/D- IEC 61000-4-2 Level 4

VBUS Discharge Requirement

USB PD Requirement: When the sink disconnects or negotiates a lower voltage, VBUS must discharge to safe levels within specified time (typically 650ms from 20V to 5V). This requires active discharge circuits.

Discharge resistor sizing: For 20V → 5V in 500ms with C = 100µF:

R = t / (C × ln(V_start/V_end)) = 0.5 / (100µ × ln(4)) ≈ 3.6kΩ → ~100mW peak dissipation
