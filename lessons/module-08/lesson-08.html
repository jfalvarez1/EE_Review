Voltage References for Data Converters

The voltage reference determines the accuracy and stability of data converter systems. Reference noise, drift, and accuracy directly limit converter performance, making reference selection critical for precision applications.

Reference Types

  • Bandgap: ~1.25V, common, moderate accuracy
  • Buried Zener: High precision, low noise
  • XFET: Ultra-low noise, precision
  • LDO-based: Simple, lower precision

Key Specifications

  • Initial accuracy: ±0.02% to ±1%
  • Temperature drift: 1-100 ppm/°C
  • Noise: 1-100 μVpp (0.1-10 Hz)
  • Long-term drift: 20-100 ppm/1000 hrs
