Pipeline ADC Architecture

Pipeline ADCs achieve high speed and high resolution by breaking the conversion into stages. Each stage resolves a few bits and passes a residue to the next stage. This parallelism allows throughput rates of 10-500+ MSPS at 10-16 bit resolution.

Pipeline Characteristics

  • Resolution: 10-16 bits typical
  • Speed: 10-500+ MSPS
  • Latency: N stages (pipeline delay)
  • Power: Moderate to high

Applications

  • Communications: IF sampling, SDR
  • Video: Image sensors, displays
  • Medical: Ultrasound, CT imaging
  • Radar: Signal processing
