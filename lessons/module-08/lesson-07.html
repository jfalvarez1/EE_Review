DAC Architectures

Digital-to-Analog Converters use various architectures to convert digital codes to analog voltages or currents. The choice of architecture depends on resolution, speed, power, and accuracy requirements.

Common Architectures

  • R-2R Ladder: Simple, low component count
  • Binary Weighted: Fast, requires matched resistors
  • Thermometer: Best DNL, high component count
  • Segmented: Combines binary + thermometer

Current vs Voltage Output

  • Voltage DAC: Direct voltage output
  • Current DAC: Needs I-V conversion
  • Multiplying DAC: Output = Vref × code
  • String DAC: Resistor divider based
