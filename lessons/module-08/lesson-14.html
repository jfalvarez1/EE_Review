Input Capture and Frequency Measurement

Input capture timers measure external signal timing with high precision. This is essential for frequency measurement, pulse width detection, and event timing. This lesson covers capture techniques and measurement accuracy.

Applications

  • Frequency meter: RPM, speed sensing
  • Pulse width: PWM decoding
  • Period measurement: Oscillator testing
  • Time stamping: Event logging

Measurement Methods

  • Period: Time between edges
  • Frequency: Edges per time
  • Reciprocal: Combined approach
  • Averaging: Improved accuracy
