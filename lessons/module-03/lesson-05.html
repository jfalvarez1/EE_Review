Precision Peak Detectors

Peak detectors capture and hold the maximum (or minimum) value of a time-varying signal. They're essential in audio level metering, power measurement, RF envelope detection, and fault monitoring systems. The precision version uses op-amps to overcome diode forward voltage drops.

Basic Principle
Capacitor charges to peak, diode prevents discharge
Op-Amp Role
Eliminates diode drop, adds buffer for load isolation

Basic vs Precision Peak Detector

The simple diode-capacitor peak detector has a 0.6-0.7V error. The precision version uses an op-amp to drive the diode, eliminating this error:

How the Precision Detector Works

The op-amp feedback eliminates diode voltage drop:

Condition Op-Amp Action Diode State Capacitor
Vin > VC Drives diode forward (VD + VC) Conducting Charges to Vin
Vin < VC Output goes negative (saturates) Reverse biased Holds peak value
Vin = VC Barely forward biases diode Threshold Stable
Key Insight: The op-amp output swings to VC + VD during charging. The feedback from VC (after diode) ensures VC = Vin exactly, regardless of diode drop.

Design Considerations

Slew Rate Limiting
Op-amp must track input: SR > 2π × f × Vpk
Acquisition Time
tacq ≈ C × ΔV / Iout,max
Parameter Effect Trade-off
Larger C Slower droop Slower acquisition, higher peak current
JFET Op-Amp Lower input bias (less droop) Often lower slew rate
Schottky Diode Faster switching Higher leakage
Buffer Amplifier Isolates load Additional offset, cost
Droop Rate: dV/dt = Ileak / C
1% Hold Time: thold = 0.01 × Vpk × C / Ileak

Applications

Application Peak Type Key Requirements
Audio VU Meter Positive (rectified) Attack ~10ms, decay ~300ms
RF Envelope Detection Positive Fast acquisition (MHz carrier)
Power Supply Monitoring Both (pk-pk) Long hold time, low droop
Vibration Analysis Both Captures shock events

Industry Tip: For audio applications, use a diode-connected transistor instead of a regular diode for smoother "soft-knee" compression characteristics.
