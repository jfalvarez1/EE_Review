Window Comparators

Window comparators detect when an input voltage is within (or outside) a defined voltage range. They're essential for limit detection, fault monitoring, battery management, and go/no-go testing in production environments.

In-Window
VLO < Vin < VHI
Output States
HIGH when in-window (typically)
