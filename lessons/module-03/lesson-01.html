Feedback Fundamentals

Feedback is the most powerful technique in analog design. It trades gain for predictability, reduces distortion, and stabilizes operating points. This lesson develops the fundamental concepts following Razavi's systematic approach.

Key Insight (Razavi): "Feedback allows us to sacrifice excess gain to achieve other desirable properties: reduced sensitivity to component variations, extended bandwidth, and lower distortion."

The Basic Feedback System

Consider the canonical feedback system:

Definitions

  • A = Open-loop gain (forward amplifier gain)
  • β = Feedback factor (fraction of output fed back)
  • Loop Gain = Aβ (the "strength" of the feedback)
  • Return Ratio = Aβ (same quantity, different context)

Closed-Loop Gain Derivation

Starting from the block diagram:

Error signal: e = xin - βxout

Output: xout = A × e = A(xin - βxout)

Solving: xout = Axin - Aβxout
         xout(1 + Aβ) = Axin

Closed-loop gain: ACL = A / (1 + Aβ)

The Feedback Approximation

When loop gain Aβ >> 1 (negative feedback is "strong"):

ACL ≈ 1/β

This is the magic of feedback: The closed-loop gain depends only on β, not on A!

Desensitization: The Power of Feedback

How sensitive is the closed-loop gain to changes in the open-loop gain A?

Sensitivity Derivation (Razavi/Agarwal Approach)

The sensitivity of ACL to A is defined as:

SACLA = (dACL/ACL) / (dA/A) = (A/ACL) × (dACL/dA)

Taking the derivative:

dACL/dA = d/dA [A/(1+Aβ)] = (1+Aβ - Aβ)/(1+Aβ)² = 1/(1+Aβ)²

Therefore:

SACLA = 1/(1+Aβ)

Interpretation: If Aβ = 99, then a 10% change in A causes only 0.1% change in ACL!

Worked Example 1: Inverting Amplifier (Art of Electronics Style)

Problem (Razavi-style)

An inverting amplifier uses an op-amp with AOL = 100,000 (100 dB). The feedback network consists of R1 = 1kΩ and R2 = 10kΩ.

  1. Find the ideal closed-loop gain
  2. Find the feedback factor β
  3. Find the loop gain Aβ
  4. Calculate the actual closed-loop gain including finite A
  5. Determine the gain error

Solution

Step 1: Ideal Closed-Loop Gain

ACL,ideal = -R2/R1 = -10k/1k = -10

Step 2: Feedback Factor

For an inverting amplifier, the feedback factor is (from voltage divider at summing node):

β = R1/(R1 + R2) = 1k/(1k + 10k) = 1/11 = 0.0909

Step 3: Loop Gain

Aβ = 100,000 × 0.0909 = 9090

Step 4: Actual Closed-Loop Gain

For the inverting configuration with finite A:

ACL = -R2/R1 × [1/(1 + (1 + R2/R1)/A)]
ACL = -10 × [1/(1 + 11/100000)]
ACL = -10 × [1/1.00011]
ACL = -9.9989

Step 5: Gain Error

Error = (|ACL| - |ACL,ideal|)/|ACL,ideal| = (9.9989 - 10)/10 = -0.011%

Conclusion: With loop gain of 9090, the gain error is only 0.011%!

The Four Effects of Negative Feedback

Feedback simultaneously affects multiple circuit parameters:

Property Without Feedback With Feedback Change Factor
Gain A A/(1+Aβ) ÷ (1+Aβ)
Sensitivity 1 1/(1+Aβ) ÷ (1+Aβ)
Nonlinearity THDOL THDOL/(1+Aβ) ÷ (1+Aβ)
Bandwidth f3dB f3dB(1+Aβ) × (1+Aβ)

Gain-Bandwidth Product Conservation

For a single-pole system, the gain-bandwidth product (GBW) is constant:

Derivation (Agarwal Approach)

If the open-loop amplifier has a single pole at fp:

A(s) = A0 / (1 + s/ωp)

The closed-loop transfer function becomes:

ACL(s) = [A0/(1+A0β)] / [1 + s/(ωp(1+A0β))]

The new closed-loop pole is at:

ωCL = ωp(1 + A0β)

Therefore:

GBW = ACL × fCL = A0 × fp = constant
