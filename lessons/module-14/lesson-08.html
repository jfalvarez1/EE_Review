Soft Start Circuit Design

Soft start prevents inrush current, reduces stress on components, and ensures controlled power-up. Learn timing design, implementation methods, and integration with power supplies.

Design Equations

Inrush Without Soft Start:
    I_inrush = Vout / (ESR + Rsource)
    Can be 10-100× normal operating current!

Soft Start Capacitor Sizing:
    Css = Iss × Tss / Vref
    Where:
        Iss = soft start current source
        Tss = desired soft start time
        Vref = reference voltage

Charging Current (voltage ramp):
    I_charge = Cout × dVout/dt = Cout × Vout / Tss

Example: 1000µF, 5V, 10ms
    I_charge = 1000µ × 5 / 10m = 0.5A

Soft Start Resistor (RC timing):
    Tss ≈ 3 × Rss × Css
    (time to reach ~95% of final value)

Power Dissipation (series R method):
    P_dissipated = 0.5 × Cout × Vout²
    All capacitor charging energy lost in R!

Active Soft Start (current limit mode):
    Tss = Cout × Vout / Ilimit
