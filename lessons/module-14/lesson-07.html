Filter Design Equations

LC Filter Corner Frequency:
    fc = 1 / (2π × √(L × C))

Filter Attenuation at fsw:
    Atten(dB) = 40 × log10(fsw / fc)  ; Above resonance

Quality Factor:
    Q = (1/R) × √(L/C)
    R = DCR + ESR

    Q > 1: Peaking at resonance (can cause instability!)
    Q = 0.707: Critically damped (Butterworth)
    Q < 0.5: Overdamped (slow response)

ESR Zero Frequency:
    fz = 1 / (2π × ESR × C)

    This limits high-freq attenuation!

Damping Resistor:
    For Q = 1: Rd = √(L/C)

Capacitor Current (ripple):
    Ic_rms = Vripple / (ESR × √2)

Output Ripple:
    Vripple ≈ IL_ripple × ESR  ; If ESR dominates
    Vripple ≈ IL_ripple / (8 × fsw × C)  ; If C dominates
