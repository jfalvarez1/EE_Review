Buck-Boost Converter Design

Buck-boost converters can step voltage up or down, ideal for battery applications where Vin crosses Vout. Learn inverting and non-inverting topologies, SEPIC, and Ćuk converters.

Use Case
Li-ion → 3.3V (2.7-4.2V in)
Key Insight: When battery voltage spans the output voltage (like Li-ion 2.7-4.2V to 3.3V), a buck-boost maintains regulation throughout the entire discharge. Buck or boost alone would lose regulation.

Design Equations

Inverting Buck-Boost:
    Vout = -Vin × D / (1 - D)
    D = |Vout| / (Vin + |Vout|)

SEPIC:
    Vout = Vin × D / (1 - D)
    D = Vout / (Vin + Vout)

    Coupling capacitor: Cc >> Cout
    Coupled inductors reduce size

4-Switch Buck-Boost:
    Buck mode (Vin > Vout): D = Vout/Vin
    Boost mode (Vin < Vout): D = 1 - Vin/Vout
    Buck-boost mode: Controlled transition

    Vswitch = max(Vin, Vout)

Component Stress:
    Inverting:
        Vsw = Vin + |Vout|
        Vdiode = Vin + |Vout|

    SEPIC:
        Vsw = Vin + Vout
        Vdiode = Vin + Vout
        Vc_coupling = Vin

    4-Switch:
        Vsw = max(Vin, Vout)  ; Lower stress!
