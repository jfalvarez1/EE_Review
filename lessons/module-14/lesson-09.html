Current Limiting Design

Current limiting protects power supplies, loads, and wiring from damage during faults. Learn foldback, constant current, and hiccup mode protection strategies.

Constant Current
Flat limit at Ilim
Foldback
Reduces I as V drops
Hiccup
Retry after timeout
Brick Wall
Hard shutdown
Design Trade-off: Constant current is best for load compatibility but causes maximum power dissipation during short. Foldback reduces dissipation but may prevent motor/capacitor loads from starting.

Current Limit Methods

Method Description Pros Cons
Cycle-by-cycle Limit peak current each cycle Fast protection Average may exceed limit
Average current Control average output current True current limit Slower response
Sense resistor Voltage across Rs Simple, accurate Power loss in Rs
RDS(on) sensing Use MOSFET as sensor No extra resistor Temperature dependent
DCR sensing Use inductor DCR Lossless Requires compensation

Design Equations

Sense Resistor:
    Rs = Vsense / Ilimit
    Power: Ps = Ilimit² × Rs

    Example: Vsense=100mV, Ilimit=3A
    Rs = 0.1/3 = 33mΩ
    Ps = 3² × 0.033 = 0.3W

RDS(on) Sensing:
    Vsense = Ids × RDS(on)
    Temperature compensation needed!
    RDS(on) ≈ RDS(on)_25C × (1 + 0.004×ΔT)

Foldback Characteristic:
    Ilim(V) = Isc + (Inom - Isc) × (V/Vnom)
    Where:
        Isc = short circuit current
        Inom = nominal current limit
        Vnom = nominal output voltage

Power Dissipation During Limit:
    Constant current: Pdiss = Vin × Ilim (worst at short)
    Foldback: Pdiss = Vin × Isc (much lower)

Hiccup Mode Timing:
    Ton = duty on time during retry
    Toff = off time between retries
    Duty = Ton / (Ton + Toff)
    Average power = Pdiss × Duty
