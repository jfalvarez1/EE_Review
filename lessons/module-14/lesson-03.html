Grounding Strategy for Mixed-Signal

Mixed-signal PCBs require careful grounding to prevent digital noise from corrupting analog signals. The key is managing return current paths.

Rule #1
One solid ground plane
Rule #2
Partition by function
Rule #3
Never cross splits
Key Insight: Return currents flow in the path of least impedance. At low frequency, this is the shortest path. At high frequency, current returns directly under the signal trace. Splits in the ground plane force return currents to detour, creating noise.

Layout Guidelines

Guideline Reason
Use unbroken ground plane Provides low-impedance return for all signals
Partition layout by function Keep noisy digital away from sensitive analog
Place ADC at analog/digital boundary Single transition point between domains
Avoid traces over plane gaps Forces return current through long path
Connect analog and digital grounds At one point, near ADC ground pin
Split Ground Myth: "Split the ground between analog and digital" is outdated advice for modern designs. A solid ground plane with proper partitioning usually works better than splits that create return current problems.

What to run: an AC sweep from 1 kHz to 1 GHz.

What to watch: VDB(gnd_a), VDB(split_a) — both driven by 1 A, so each curve is that ground path's impedance in dBΩ.

Two flat regions and two rising ones, and the interesting part is which gap is which. At 1 kHz they sit at −60 and −40 dB: 1 mΩ against 10 mΩ, a resistance ratio of ten. At 1 GHz they are at 10 and 36 dB — 3.14 Ω against 62.8 Ω, an inductance ratio of twenty. Each curve turns where ωL = R, at 318 kHz for the plane and 159 kHz for the split.

Above those corners the resistance is irrelevant and only the inductance matters, and inductance is set by loop area, which is exactly what a split makes worse. That is the argument against splitting a ground plane in one graph: the split was supposed to keep digital return current out of the analogue section, and at the frequencies where that current is actually a problem the split has made the impedance twenty times higher.
