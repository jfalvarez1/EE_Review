BJT Output Stages

Output stages deliver power to loads. Class A provides linearity but low efficiency. Class B offers efficiency but crossover distortion. Class AB combines the best of both, using a small quiescent current to eliminate crossover while maintaining high efficiency.

Class A
Max efficiency 25%, no crossover
Class B
Max efficiency 78.5%, crossover distortion
Class AB
Efficiency ~60-70%, minimal distortion
Key Design
VBE multiplier sets quiescent current

The circuit

A complementary class AB output stage. Q1 sources current into the load on positive half-cycles and Q2 sinks it on negative ones; the VBE multiplier Q3 holds their bases about two diode drops apart so that neither device ever fully turns off, which is what removes the crossover distortion a class B stage would have.

Re1 and Re2 are the emitter degeneration resistors. They set the quiescent current together with the bias voltage, and — more importantly — they give the stage a negative temperature coefficient of current, which is what stops thermal runaway. See the thermal section below.

VBE Multiplier Bias Circuit

The VBE multiplier sets the voltage drop between the output transistor bases, controlling quiescent current:

Voltage Drop
Vbias = VBE(1 + R1/R2)
Typical Value
~1.2-1.4V for NPN/PNP pair

Adjustment
