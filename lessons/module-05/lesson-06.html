Common-Emitter Amplifier

The common-emitter (CE) configuration is the most widely used BJT amplifier topology. The input is applied to the base, output taken from the collector, and the emitter is common to both (often through a degeneration resistor).

Voltage Gain (with RE)
Av = −RC / (RE + re)
Voltage Gain (no RE)
Av = −gm × RC = −RC/re
Key Insight: The minus sign indicates 180° phase inversion. Emitter degeneration (RE) reduces gain but dramatically improves linearity and temperature stability.

Design Equations

For a well-designed CE amplifier with VC at mid-rail:

Step Equation Purpose
1 RC = VCC / (2 × IC) Sets collector at VCC/2
2 RE = RC/|G| − re Sets gain with degeneration
3 VB = IC×RE + 0.6V Base voltage for bias
4 R1||R2 ≈ 0.1 × β × RE Stiff bias divider
Design Trade-off: Higher gain requires smaller RE, which increases sensitivity to temperature and transistor variations. For gains > 50, consider cascading stages.

When added in parallel with RE, the capacitor shorts RE at AC frequencies, increasing gain to gm×RC but reducing input impedance.

DC Load Line Analysis

The load line shows all possible DC operating points for a given RC and VCC. The Q-point is where the load line intersects the transistor's IC-VCE curve.

Load Line Equation

KVL around output
VCE = VCC - IC(RC+RE)

Key Points

IC = 0VCE = VCC(cutoff)
VCE = 0IC = VCC/(RC+RE)(saturation)
Q-pointVCE ≈ VCC/2(optimal)
Clipping: Output swing is limited to the range between saturation (VCE(sat) ≈ 0.2V) and cutoff (VCE = VCC).

Input and Output Impedance

Understanding impedance is critical for properly interfacing the amplifier with source and load.

Input Impedance

Looking into base
Zin(base) = β(re + RE)
Including bias network
Zin = R1 || R2 || Zin(base)

With bypass capacitor CE (RE shorted at AC):

Bypassed
Zin(base) = β × re = β × VT/IC

Output Impedance

At collector
Zout ≈ RC || ro
With Early effect
ro = VA/IC

Since ro >> RC typically:

Approximate
Zout ≈ RC
Example: At IC=1mA, β=150:
Without bypass: Zin ≈ 150×(26Ω+1kΩ) ≈ 154kΩ
With bypass: Zin ≈ 150×26Ω ≈ 3.9kΩ

Frequency Response and Miller Effect

The CE amplifier has limited bandwidth due to transistor capacitances, especially the Miller-multiplied Cbc.

Miller Effect

The base-collector capacitance Cbc appears multiplied by the voltage gain when looking into the base:

Miller Capacitance
CMiller = Cbc × (1 + |Av|)
Input Pole
fH ≈ 1/(2π Rs CMiller)

Typical Capacitances (2N3904)

Cbe (Cπ)~30-50pF @ 1mA
Cbc (Cμ)4pF @ VCB=5V
fT300MHz
Gain-Bandwidth Trade-off:
Higher gain → Higher CMiller → Lower bandwidth.
Solution: Use cascode configuration to eliminate Miller effect.
