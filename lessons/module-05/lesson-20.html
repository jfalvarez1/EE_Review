Industry MOSFET Selection Guide

Selecting the right MOSFET for a power application involves balancing many parameters. This lesson provides a systematic approach used by practicing engineers to navigate datasheets and make optimal device selections for real-world designs.

The Selection Process

  1. Define application requirements
  2. Calculate voltage and current ratings
  3. Estimate power losses
  4. Check thermal feasibility
  5. Verify gate drive compatibility
  6. Consider package and layout
  7. Evaluate cost and availability

Step 2: Voltage and Current Ratings

Current Rating Considerations

  • ID continuous: Datasheet rating at Tc=25°C - derate for actual temp
  • ID pulsed: For transient currents - check SOA chart
  • RMS vs peak: Use RMS for loss calculations, peak for SOA
  • Thermal limit: Often Rds(on) × I² heat, not package ID limit

Step 5: Gate Drive Requirements

ParameterWhat to CheckTypical Values
Vgs(th) Must be below gate drive voltage 1-4V (logic level: 1-2V)
Vgs(max) Gate driver output must not exceed ±20V typical, ±6V for GaN
Qg (total) Driver current × switching time 10-100nC for power MOSFETs
Qgd (Miller) Affects switching loss and dV/dt 5-50nC typically
Rg (internal) Part of gate drive impedance 0.5-5Ω

Gate Drive Current Calculation

Ig = Qg × fsw

Example: 30nC at 500kHz = 30nC × 500kHz = 15mA average

Peak current = Qg / (tr or tf) can be several amps!

Logic Level vs Standard

Standard gate: Needs 10-12V for full enhancement

Logic level: Full enhancement at 4.5V, usable at 3.3V

Match MOSFET type to controller gate drive capability!

What to WatchRed FlagWhat It Means
Rds(on) conditions Spec'd at Tj=25°C, Vgs=10V Multiply by 1.5-2× for hot operation
ID continuous rating Tc=25°C assumption Actual current limited by Rds(on) heating
SOA graph missing No linear mode data Avoid for hot-swap/inrush limiting
Avalanche rating No EAS specification Don't use for inductive loads without clamp
Qrr (body diode) High Qrr value Higher losses in sync rectification
Thermal resistance Only Rθja given, no Rθjc Can't calculate heatsink requirements
