BJT in Feedback Amplifiers

Negative feedback trades gain for improved linearity, bandwidth, and predictable impedances. The four feedback topologies (series-shunt, shunt-series, series-series, shunt-shunt) each modify input and output impedance differently while stabilizing gain.

Key Benefit
Af = A/(1+Aβ) → 1/β when Aβ >> 1
Bandwidth
BWf = BW(1+Aβ)
Distortion
THD reduced by (1+Aβ)
Sensitivity
dAf/Af = (dA/A)/(1+Aβ)

The circuit

The classic two-transistor series–shunt pair: Q1 is a common-emitter stage, Q2 an emitter follower, and Rf returns from the follower's emitter to Q1's emitter. That return path is what closes the loop, and where it is taken from is what makes this series–shunt rather than any of the other three topologies.

Closed-loop gain is set almost entirely by the resistor ratio, \(A_v \approx 1 + R_f/R_{E1}\), and is therefore as stable as two resistors — not as stable as \(\beta\), which varies three to one part to part and with temperature. That substitution, trading raw gain for a gain you can predict, is what feedback buys and it is the same trade an op-amp makes.
