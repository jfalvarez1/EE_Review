BJT Noise Analysis

Understanding noise is critical for low-level signal amplification. BJTs have several noise sources that determine the minimum detectable signal in audio, sensor, and RF front-ends.

Dominant Sources
Shot noise, thermal noise, 1/f noise
Key Metric
Noise Figure (NF) in dB
Industry Use: Low-noise preamps for MEMS microphones, photodiode amplifiers, RF LNAs, precision instrumentation.

Equivalent Input Noise

Refer all noise sources to the input for easier analysis:

Input Voltage Noise
en² = 4kTrb + 2kT/gm
Input Current Noise
in² = 2qIB

Total equivalent input noise with source resistance Rs:

Total vn,eq
√(en² + in²Rs² + 4kTRs)
Key Insight: There's an optimal source impedance where noise is minimized. For BJTs, typically Rs,opt = en/in ≈ √(rb/IC) × √(2kT/q).

Noise Figure (NF)

Definition
NF = 10 log₁₀(SNRin/SNRout) dB
Ideal Amplifier
NF = 0 dB (adds no noise)

For a BJT:

NF Formula
NF = 1 + rb/Rs + (1 + Rs/rb)/(2gmRs)
Minimum NF
At Rs,opt = rb√(1 + gmrb)
NF (dB) Quality Application
< 1 Excellent RF LNA, radio astronomy
1-3 Good Audio preamps, sensors
3-6 Moderate General purpose
> 6 Poor May dominate system noise

1/f Noise Corner Frequency

Below a certain frequency, 1/f noise dominates over white noise:

Typical fc
100Hz - 10kHz for BJTs
Lower is Better
High-quality BJTs: fc < 100Hz

For audio applications (20Hz - 20kHz), 1/f noise matters at low frequencies. Choose transistors with low fc or use chopper stabilization for DC signals.

Low-Noise Design Guidelines

Strategy Implementation Trade-off
Match Rs to Ropt Transformer or LC matching network Complexity, bandwidth
Increase IC Higher bias current Power, reduces rπ
Choose low rb BJT Use low-noise parts (2SC3324, MAT02) Cost
