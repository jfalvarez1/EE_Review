BJT SPICE Modeling

SPICE uses the Gummel-Poon model to simulate BJT behavior. Understanding model parameters helps interpret simulation results and create accurate models from datasheet specs.

Essential SPICE Parameters

Parameter Name Typical Value Physical Meaning
IS Saturation current 1e-14 to 1e-16 A Exponential I-V intercept
BF Forward β 100-400 Maximum forward current gain
BR Reverse β 0.1-10 Current gain in reverse active
VA (VAF) Early voltage 50-200V Output resistance: ro = VA/IC
TF Forward transit time 0.1-1ns Related to fT: fT ≈ 1/(2π·TF)
CJE B-E junction capacitance 5-50pF Input capacitance component
CJC B-C junction capacitance 2-20pF Miller capacitance source
