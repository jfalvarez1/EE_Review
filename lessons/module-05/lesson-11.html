The Differential Pair

The differential pair is the fundamental building block of operational amplifiers. It consists of two matched transistors sharing a common emitter current source, providing high gain for differential signals while rejecting common-mode noise.

Differential Gain
Gdiff = gm × RC
With Degeneration
Gdiff = RC / (2RE + 2re)
Key Insight: The differential pair converts a differential voltage to a differential current, then to a single-ended voltage. The tail current source sets the operating point and provides common-mode rejection.

Circuit Topology: Long-Tail Pair

The "long-tail pair" refers to the high-impedance tail, whether implemented as a resistor (simple) or current source (better). Compare these two implementations:

Historical Note: The term "long-tail pair" comes from early vacuum tube days where a high-value "tail" resistor was used to approximate a current source. The longer the tail (higher impedance), the better the common-mode rejection.

Transfer Curve Analysis

The differential pair transfer function follows a hyperbolic tangent:

Current Split
IC1 = Itail/2 × (1 + tanh(Vdiff/2VT))
Vdiff IC1 IC2 Region
0 mV Itail/2 Itail/2 Balanced
±26 mV 0.73 or 0.27 × Itail 0.27 or 0.73 × Itail Linear edge

Linear Region: The diff pair is only linear for |Vdiff| < 2VT ≈ 52mV. Beyond this, it becomes a soft limiter. This is why op-amps need negative feedback!

Common-Mode Rejection

The tail current source is the key to CMRR. An ideal current source has infinite impedance, making common-mode gain zero.

CMRR Definition
CMRR = Gdiff / Gcm
With Current Source
CMRR = gm × Rtail
Tail Type Rtail CMRR (typical)
Resistor ~kΩ 40-60 dB
Simple current mirror ~100kΩ 80 dB
Wilson/Cascode mirror ~MΩ >100 dB

CMRR Analysis: The Complete Picture

Let's derive why tail impedance matters so much. Consider what happens when both inputs move together (common-mode):

Differential Mode: V1 increases, V2 decreases → IC1 increases by ΔI, IC2 decreases by ΔI → Tail current unchanged (currents cancel at emitter node).
Common Mode: V1 and V2 increase together → Both VBE try to increase → This would increase both IC1 and IC2 → But tail current is fixed! → Emitter voltage rises to compensate → Output barely changes.

Mathematical Derivation

For a common-mode input Vcm applied to both bases:

Common-Mode Gain
Acm = -RC / (2Rtail + re)
Differential Gain
Adiff = gmRC = RC/re

Taking the ratio (and since 2Rtail >> re):

CMRR Derivation
CMRR = Adiff/Acm = (RC/re) × (2Rtail/RC) = 2Rtail/re = 2gmRtail

Design Rule (Art of Electronics): To achieve 80dB CMRR, you need Rtail > 50kΩ at 1mA (gm = 38mS). A simple current mirror provides ~100kΩ; Wilson or cascode mirrors can exceed 1MΩ.

Op-Amp Input Stage Connection

The differential pair is the universal input stage for operational amplifiers. Understanding this connection is key to understanding op-amp behavior.

Op-Amp Parameter Diff Pair Origin How to Improve
Input Offset Voltage (Vos) VBE mismatch between Q1, Q2 Laser trim, chopper stabilization
Input Bias Current (Ib) Base current = IC/β Use JFET/MOSFET input, super-β BJTs
Input Offset Current (Ios) β mismatch between Q1, Q2 Better matching, current cancellation
CMRR Tail current source impedance Cascode/Wilson tail, better matching
Slew Rate Itail / Ccompensation Higher tail current, smaller comp cap
Open-Loop Gain gm × Rload Active loads (current mirrors)
The 741 Inside: The classic µA741 op-amp uses a bipolar differential pair input with a current mirror active load. This converts the differential current to single-ended, then feeds a CE gain stage with Miller compensation, and finally a push-pull output.
