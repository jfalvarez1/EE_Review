Buck (Step-Down) Converter

The buck converter efficiently steps down voltage using a switch, inductor, and capacitor. Unlike linear regulators, it can achieve >90% efficiency even with large voltage differentials.

Output Voltage
Vout = Vin × D
Duty Cycle
D = Vout/Vin
Key Insight: The buck converter works by storing energy in an inductor during switch-on and releasing it to the load during switch-off. The LC filter averages the switching waveform.

Buck Converter Topology

The synchronous buck uses two MOSFETs: high-side (HS) connects input to switch node, low-side (LS) provides freewheeling path:

Switch Node (SW)
Swings between Vin and GND
Inductor
Stores energy, averages SW voltage
Output Cap
Filters ripple, provides transient energy

Continuous vs Discontinuous Mode

Parameter CCM (Continuous) DCM (Discontinuous)
Inductor current Never reaches zero Reaches zero each cycle
Vout/Vin = D (duty cycle) Complex function of L, f, load
Control loop Simpler, predictable Load-dependent transfer function
Efficiency Higher at full load Can be higher at light load
Critical Inductance
Lcrit = Vout(1−D)/(2×Iout×fsw)

Component Selection

Component Key Parameters Selection Criteria
Inductor L, Isat, DCR Isat > Ipk, low DCR for efficiency
Output Cap C, ESR Low ESR for ripple, adequate C for transient
High-Side FET RDS(on), Qg Balance conduction vs switching loss
Low-Side FET/Diode VF or RDS(on) Sync FET for high efficiency
