MOSFET Safe Operating Area (SOA)

The Safe Operating Area defines the voltage and current limits within which a MOSFET can operate without damage. Understanding SOA is critical for hot-swap circuits, linear mode operation, and any application where the MOSFET must handle simultaneous high voltage and current.

SOA Limits
Voltage, Current, Power, Second breakdown
Critical Application
Linear mode (Vds ≠ 0 while conducting)

Thermal Limit P = Vds × Id = constant (Tj,max) Thermal resistance θJC, pulse width

Vds Maximum Avalanche breakdown Voltage rating, temperature
Linear Mode Danger: When operating in the linear region (Vds >> 0 while conducting current), the MOSFET dissipates significant power. This is common in hot-swap, electronic load, and linear regulator applications.

Spirito Effect (Hot Spotting)

In linear mode at high Vds, current can focus into a small portion of the die, causing localized overheating:

Why It Happens: In saturation/linear mode, hotter cells have lower Vth and conduct more current, which heats them further → positive feedback loop → thermal runaway.
