MOSFET Fundamentals

The MOSFET (Metal-Oxide-Semiconductor Field-Effect Transistor) is a voltage-controlled device that dominates modern electronics. Unlike BJTs, MOSFETs have virtually infinite input impedance and a square-law transfer characteristic.

Drain Current (saturation)
ID = (µCoxW/2L)(VGS − Vth)²
Simplified
ID = K(VGS − Vth)²
Key Difference from BJT: MOSFETs have square-law (not exponential) characteristic and draw essentially zero gate current. This makes them ideal for high-impedance inputs and switching applications.

Operating Regions

Region Condition ID Equation Behavior
Cutoff VGS < Vth ID ≈ 0 Off (switch open)
Linear (Triode) VDS < VGS − Vth ID = K[2(VGS−Vth)VDS − VDS²] Resistor (switch on)
Saturation VDS ≥ VGS − Vth ID = K(VGS−Vth)² Current source (amplifier)

Transconductance

MOSFET transconductance is proportional to the square root of drain current:

Definition
gm = ∂ID/∂VGS = 2K(VGS−Vth)
In terms of ID
gm = 2√(K×ID)
Lower than BJT: At the same current, a MOSFET has much lower gm than a BJT. BJT: gm = IC/VT = 40×IC(mA). MOSFET: gm = 2√(K×ID), typically 5-10× lower.
