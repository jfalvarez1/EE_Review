EMC/EMI Fundamentals

Electromagnetic Compatibility (EMC) ensures your product neither emits excessive interference nor is susceptible to external electromagnetic fields. Understanding EMC from the design phase prevents expensive redesigns and certification failures.

EMI
Electromagnetic Interference - unwanted emissions
EMS
Electromagnetic Susceptibility - immunity to external noise

EMI Coupling Mechanisms

Coupling Type Mechanism Mitigation
Conducted Noise on power/signal cables Filters, ferrites, isolation
Radiated E-field Voltage differences create fields Shielding, reduce loop area
Radiated H-field Current loops create magnetic fields Reduce loop area, twisted pairs
Ground loops Multiple ground paths with voltage differences Single-point ground, isolation

Common EMI Sources

Source Frequency Design Consideration
Digital clocks Fundamental + harmonics Use spread-spectrum clocking where possible
Switch-mode power supplies Switching frequency (50kHz-2MHz) Input filter, snubbers, slow edges
High-speed digital I/O Edge rate dependent Series termination, controlled impedance
Motor drives PWM frequency and harmonics Shielded cables, common-mode chokes
Crystal oscillators Fundamental frequency Ground rings, local decoupling
EMI Bandwidth: fknee ≈ 0.35 / trise

Example: 1ns rise time → harmonics significant up to 350MHz

EMI Mitigation Techniques

Cx (X capacitor)
Line-to-line, differential mode filter
Cy (Y capacitor)
Line-to-ground, common mode filter
Y Capacitor Limits: Safety standards limit Y capacitors (typically ≤4.7nF) to prevent dangerous leakage current to the enclosure ground.

PCB Layout for EMC

Practice Purpose
Solid ground plane Low-impedance return path, reduces loop area
Keep high-speed signals short Shorter traces = smaller antennas
Decoupling caps near ICs Provide local charge, reduce power plane noise
No splits under high-speed traces Return current follows signal path
Guard rings around clocks Contain electric fields
Filter all I/O at board edge Prevent cable radiation
