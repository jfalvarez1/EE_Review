Test Equipment Essentials

Beyond the oscilloscope, hardware engineers need proficiency with multimeters, LCR meters, power supplies, and specialized equipment. Understanding each instrument's capabilities and limitations enables efficient debugging and accurate measurements.

Core Equipment
DMM, Oscilloscope, Power Supply, LCR Meter
Key Skill
Knowing when measurement affects the circuit

Digital Multimeter (DMM) Specifications

Spec Budget DMM Bench DMM Precision DMM
Resolution 3½ digit (1999) 4½ digit (19999) 6½+ digit
DC Accuracy ±0.5% ±0.05% ±0.002%
Input Impedance 10MΩ 10MΩ (>10GΩ on low ranges) >10GΩ
True RMS No (average-responding) Yes Yes, wide bandwidth
Examples UNI-T UT61E Fluke 87V, Keysight U1282A Keysight 34461A, Fluke 8846A
True RMS: Essential for measuring non-sinusoidal waveforms (PWM, distorted AC). Average-responding meters give incorrect readings for anything other than pure sine waves.

LCR Meter Fundamentals

LCR meters measure inductance, capacitance, and resistance with impedance analysis:

Measurement Primary Parameter Secondary Parameter Test Frequency
Capacitor C (capacitance) D (dissipation factor) or ESR 100Hz-1kHz typical
Inductor L (inductance) Q (quality factor) or DCR 1kHz-100kHz typical
Resistor R (resistance) X (reactance) DC or low frequency
Crystal Cs, Cp ESR, Q Near resonance
Dissipation Factor: D = ESR × ω × C = 1/Q
Test Frequency Matters: Capacitor ESR and inductor core losses are frequency-dependent. Measure at the actual operating frequency when possible.

Power Supply Considerations

Feature Importance Typical Spec
Output Noise Critical for analog/RF < 1mVpp
Load Regulation Voltage stability under load < 0.01%
Current Limit Protection during debug Adjustable, foldback optional
Sense Lines Compensate cable drops 4-wire for precision
Slew Rate Transient response testing Varies widely
Lab Supply Current Limits: Always set current limit before powering a new design. Start with ~100mA for low-power circuits. This prevents catastrophic damage from shorts or design errors.
