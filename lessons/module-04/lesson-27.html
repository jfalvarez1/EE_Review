BJT Output Stages

Output stages deliver power to loads. Class A provides linearity but low efficiency. Class B offers efficiency but crossover distortion. Class AB combines the best of both, using a small quiescent current to eliminate crossover while maintaining high efficiency.

Class A
Max efficiency 25%, no crossover
Class B
Max efficiency 78.5%, crossover distortion
Class AB
Efficiency ~60-70%, minimal distortion
Key Design
VBE multiplier sets quiescent current

VBE Multiplier Bias Circuit

The VBE multiplier sets the voltage drop between the output transistor bases, controlling quiescent current:

Voltage Drop
Vbias = VBE(1 + R1/R2)
Typical Value
~1.2-1.4V for NPN/PNP pair
Thermal Tracking
Mount bias transistor on heatsink
Adjustment
Trimpot for R2 sets IQ
