Analog Signal Conditioning for ADCs

Before digitizing, analog signals typically need conditioning: amplification, filtering, level shifting, and protection. Poor conditioning wastes ADC resolution and introduces errors.

Key Insight: The anti-aliasing filter must attenuate signals above fs/2 (Nyquist) to prevent aliased frequencies from appearing in the digitized output. Higher order filters allow sampling closer to the signal bandwidth.

Anti-Alias Filter Requirements

Filter Order Rolloff Attenuation at fs/2 Typical Use
1st order 20 dB/decade 14.15 dB (Butterworth, fc = fs/10) 8-10 bit ADCs
2nd order 40 dB/decade 27.97 dB (Butterworth, fc = fs/10) 12 bit ADCs
4th order 80 dB/decade 55.92 dB (Butterworth, fc = fs/10) 16+ bit ADCs
Set an alias-error budget: required attenuation is 20 log10(unfiltered interferer amplitude / allowed alias amplitude), at each frequency that folds into the measurement band. Resolution alone does not specify either amplitude. The calculator below assumes a full-scale sine interferer (Vref/2 peak) and allows half an LSB, giving 6.0206N dB. Change that budget for the actual interferers and noise; also check passband loss. Analog Devices, Filter Basics: Anti-Aliasing.

A numerical acceptance contract

U1 now has gain 1 + 27 kΩ/1 kΩ = 28. The 50 mV peak input becomes 1.40 V peak about 1.65 V, leaving nominal 0.25 V margins to a 0–3.3 V range. Those margins are a design target; check the selected amplifier’s input common-mode and loaded output-swing limits.

For this equal-R, equal-C unity-gain Sallen-Key stage, Q = 1/(3 − 1) = 0.5 and f0 = 1/(2πRC) = 10.01 kHz. Its response is H(s) = 1/(1 + sRC)², so f−3dB is only 0.644f0, about 6.44 kHz. It is not the Butterworth example used by the general calculator. At 1 kHz the expected output is 1.40/[1 + (2πfRC)²] = 1.386 V peak.

Bench acceptance: verify the 1.65 V bias first; then measure amplitude and phase across both stages. Inject an out-of-band tone of known amplitude and inspect the acquired ADC spectrum at its alias frequency. The build contains no sampling capacitor, acquisition timing, op-amp rails or settling model, so it cannot establish ADC accuracy, rail compliance or clamp survival. Rail diodes also require current limiting and a supply that can accept their current.

Reference: TI SLOA024B, sections 3.4 and 3.5 supplies the Sallen-Key equations and explains where finite amplifier bandwidth changes the response.

Then change one thing at a time and predict the result before you run it. A simulator is only worth the time if you are checking an answer you already have — otherwise it is a very slow way of being surprised.
