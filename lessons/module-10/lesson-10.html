Debugging Analog Circuits

Analog debugging requires systematic methodology and deep circuit understanding. Unlike digital circuits where signals are valid or invalid, analog circuits have infinite failure modes. This lesson covers practical debugging strategies for real-world analog issues.

First Rule
Verify power supplies before anything else
Key Skill
Hypothesis-driven debugging

Debugging Methodology

Power Supply Checks

Most analog problems trace back to power issues. Always check these first:

Check Expected Problem Indicates
DC voltage level Within ±5% of nominal Regulator issue, excessive load
Ripple/noise (AC coupled) < 10mVpp typical Bad decoupling, regulator oscillation
Current consumption Near calculated value Short, wrong component, oscillation
Transient response Quick recovery, no overshoot Insufficient capacitance, instability
Hidden Oscillation: A regulator or op-amp may oscillate at MHz frequencies invisible to a DMM. Always check power rails with an oscilloscope (>100MHz bandwidth).

Op-Amp Debugging Checklist

Rail-to-Rail Misconception: Even "rail-to-rail" op-amps need 50-100mV headroom. Check datasheet output swing specification.

Common Analog Issues

Symptom Possible Causes How to Identify
Output stuck at rail Open feedback loop, saturated input, power issue Check feedback resistor, measure input voltages
Oscillation Insufficient phase margin, capacitive load Scope shows ringing, add compensation
Offset voltage too high Bias current × resistance mismatch, Vos Calculate expected offset, compare
Gain too low Wrong resistor values, loading effect Measure resistor values, check load impedance
Gain too high Wrong values, positive feedback (oscillation) Verify component values and polarity
Noise on output Power supply noise, ground loops, pickup Measure supply, shield/filter inputs
Distortion Slew rate limit, clipping, crossover Reduce frequency/amplitude, check waveform

Oscillation Diagnosis

Op-amp oscillation is a frequent problem. Key indicators and fixes:

Cause Solution
Capacitive load Add isolation resistor (10-100Ω) or use in-loop compensation
Long feedback path Keep feedback components close to op-amp
Stray capacitance in feedback Add small capacitor (1-10pF) across feedback resistor
Unity-gain stability Use unity-gain stable op-amp or add gain

Divide and Conquer

For complex circuits, isolate sections:

  1. Break the signal chain: Disconnect stages and test individually
  2. Inject test signals: Apply known signal at each stage input
  3. Compare to simulation: Verify each stage matches SPICE results
  4. Check node impedances: Loading from next stage may affect previous
  5. Substitute components: Replace suspect parts with known-good ones
The "Freeze Spray" Test: Temperature-sensitive issues can be found by cooling components with freeze spray. If behavior changes dramatically, that component may be marginal or have a thermal problem.
