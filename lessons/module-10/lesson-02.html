Real-World Component Selection Scenarios

Industry-sourced examples showing critical component selection decisions.

1. Precision ADC Reference Resistor Divider

Application: Voltage reference divider for 16-bit SAR ADC (±1 LSB accuracy required)

Challenge. Work in LSBs, because that is the only unit that answers the question. With a 4.096 V reference, 16 bits makes one LSB 62.5 µV. Take a divider down to 2.048 V: to hold ±1 LSB there, the ratio has to stay inside 62.5 µV / 2.048 V = 30 ppm over the whole temperature range.

What matters is not each resistor's tempco but the difference between them — a divider is a ratio, and a drift both halves share cancels. Two separate ±100 ppm/°C thick-film parts are specified only as ±100 each, not as matched, so their ratio can move up to 200 ppm/°C. Over a 100 °C range that is 20 000 ppm = 2%, or 41 mV = 655 LSB. A matched thin-film network tracking to 5 ppm/°C gives 500 ppm over the same range — 1.0 mV, 16 LSB. Better by forty times, and still not one LSB.

Which is the real lesson: ±1 LSB over 100 °C would need 0.3 ppm/°C of tracking, and you cannot buy that. So precision designs do not divide a reference and hope — they measure ratiometrically, exciting the sensor from the same reference that feeds the ADC, at which point the reference's drift cancels out of the answer entirely and the divider's tracking is all that is left.

  • Solution: Use Vishay TNPW series thin film resistors (±10ppm/°C, 0.1% tolerance)
  • Design tip: Match resistor tempcos by using same part number from same reel
  • Ratio tracking: Even if both resistors drift, matched parts maintain ratio

Reference: Vishay Thin Film Resistor Selection Guide, TI Application Note SLAA872

2. Buck Converter Output Capacitor Selection

Common Mistake: Using a 22µF X7R capacitor rated for 16V at 12V DC bias—actual capacitance drops to ~12µF!

Why it matters: Switching converters rely on output capacitance for ripple filtering. Underestimating DC bias derating causes excessive ripple, loop instability, or audible noise.

  • Solution 1: Use 25V-rated caps at 12V for ~60% of actual capacitance
  • Solution 2: Use multiple smaller caps in parallel (better ESR, redundancy)
  • Solution 3: Add polymer or electrolytic bulk capacitance for low-frequency energy

For high-reliability designs, use Murata's SimSurfing tool to see actual capacitance vs. voltage and temperature curves for specific part numbers.

Reference: Murata Technical Note No.C02, TI Power Supply Design Seminar SEM2100

3. High-Side Current Sense Resistor

Application: 10A battery current sensing with ±1% accuracy

  • Resistance choice: 10mΩ for 100mV full-scale (within INA219 input range)
  • Power dissipation: I²R = 10² × 0.01 = 1W continuous
  • Kelvin connection: Use 4-wire sensing pads to eliminate PCB trace resistance error
  • Inductance: Choose low-inductance metal element type (Bourns CSS, Vishay WSL)
  • TCR: Standard ±50ppm/°C is adequate; self-heating is bigger concern
Design tip: Calculate thermal rise: ΔT = P × θJA. A 1W resistor with 70°C/W thermal resistance rises 70°C above ambient. This affects nearby components and the resistor's own temperature coefficient drift.

Reference: TI Application Report SLVA458, Vishay Precision Current Sensing Guide

4. MLCC Piezoelectric Noise (Singing Capacitor)

Problem: Users report audible buzzing from a smartphone charger at low load. Root cause: X7R/X5R capacitors in the feedback network exhibit piezoelectric effect, converting voltage ripple to mechanical vibration.

  • Frequency: Switching frequencies 1-10kHz or their harmonics fall in audible range
  • Worst offenders: Large case sizes (0805-1206) with high capacitance density
  • Solution 1: Use C0G dielectric (no piezoelectric effect) for feedback network
  • Solution 2: Use flex-tolerant termination (soft-term) capacitors
  • Solution 3: Change switching frequency above 20kHz

Reference: Murata Application Note "Acoustic Noise from MLCC", TDK MLCC Application Manual

5. Op-Amp Power Supply Bypassing

Application: Precision instrumentation amplifier (INA128) for strain gauge bridge

Failure mode: Using only 100nF X7R bypass caps causes 60Hz PSRR degradation at low frequencies where X7R has lowest capacitance due to DC bias.
  • Standard approach: 100nF C0G + 10µF X7R on each supply rail
  • C0G: Provides stable, high-Q decoupling at high frequencies
  • X7R: Provides bulk energy storage for transient loads
  • Placement: C0G closest to IC pins (short loop), X7R can be slightly farther

Reference: TI Application Note SBAA285, Analog Devices AN-202

6. Inductor Saturation in DC-DC Converters

Scenario: A 5V/3A buck converter works at room temperature but fails during cold start at -40°C.

  • Root cause: Ferrite inductor saturation current drops 20-30% at cold temperatures
  • Symptom: Inductance drops suddenly, causing current runaway and overcurrent shutdown
  • Solution 1: Choose inductor with 40% Isat margin above peak current
  • Solution 2: Use powdered iron core (soft saturation, less temperature variation)
  • Solution 3: Implement soft-start to limit inrush current

Check manufacturer saturation curves at temperature extremes. Würth Elektronik and Coilcraft provide temperature-dependent saturation data.

Reference: Coilcraft Document 1047, TI Application Note SLVA704

7. ESD Protection Capacitance Loading

Application: USB 2.0 data line ESD protection

USB 2.0 high-speed mode requires <75pF load capacitance per data line. Many TVS diodes add 5-50pF.

  • Wrong choice: Standard TVS array (20pF per line) + connector (5pF) + trace (3pF) = 28pF × 2 lines = failing margin
  • Right choice: Low-capacitance TVS like NXP PESD5V0S2BT (<1pF)
  • Trade-off: Lower capacitance often means higher clamping voltage—verify against VBUS max ratings

Reference: ON Semiconductor AND9201, NXP Application Note AN10881

8. Thermal Runaway in Power Resistors

Scenario: A 1W bleeder resistor in a power supply fails after months of operation.

  • Mechanism: Resistor heats up → ambient rises → derated power drops → resistor heats more → thermal runaway
  • Design error: 0.8W dissipation in 1W resistor seems fine at 25°C, but at 85°C ambient, derated allowance may be only 0.5W
  • Solution: Derate to 50% of nominal rating for reliable long-term operation
  • Enhanced solution: Use 2W resistor for 1W load (100% margin)

Reference: Vishay Application Note "Resistor Power Rating and Derating"

9. Crystal Load Capacitor Selection

Application: 32.768kHz crystal for RTC with 12.5pF load capacitance specification.

  • Formula: CL = (C1 × C2) / (C1 + C2) + Cstray
  • Stray capacitance: Typically 2-5pF from PCB traces and IC pins
  • Example: CL=12.5pF, Cstray=3pF → need (C1×C2)/(C1+C2) = 9.5pF
  • Solution: Use 18pF or 20pF caps (18×18)/(18+18) = 9pF + 3pF = 12pF
Frequency pulling: Wrong CL causes frequency error. For 32.768kHz crystals, 1pF error can cause minutes/month timekeeping drift. Use C0G capacitors only!

Pierce oscillator: C1, C2 provide load capacitance; Rf provides DC bias

10. TVS Diode Selection for USB ESD

Application: USB 2.0 port protection (ESD per IEC 61000-4-2)

  • Working voltage: 5.5V (above USB VBUS max)
  • Clamping voltage: <30V at 8kV contact discharge (protects USB PHY)
  • Capacitance: <5pF for data lines (USB 2.0 HS needs <10pF total)
  • Response time: <1ns (TVS diodes are inherently fast)
Gotcha: Cheap TVS arrays may have 20-50pF capacitance that kills USB high-speed mode. Always check datasheet capacitance specs!

11. Ferrite Bead Selection for Power Filtering

Application: Filter switching noise from 3.3V rail supplying sensitive ADC.

  • Impedance spec: Look for impedance at target frequency (e.g., "100Ω @ 100MHz")
  • DC resistance: Low DCR (<0.5Ω) to minimize voltage drop
  • Current rating: Must exceed maximum load current with margin
  • Impedance vs frequency: Ferrites are inductive at low frequencies, resistive at resonance

Ferrite bead impedance: |Z|, R (resistive loss), X (reactive). Best filtering at peak |Z|.

13. MOSFET Gate Driver Resistor Selection

Application: Gate drive for synchronous buck converter MOSFET.

  • Turn-on speed: Faster = lower switching loss, but more EMI
  • Gate resistor: Limits di/dt and dv/dt, controls ringing
  • Typical values: 1-10Ω for power MOSFETs, 22-47Ω for IGBTs
  • Split resistors: Use diode + separate Rg for asymmetric on/off times

14. Schottky Diode for Reverse Polarity Protection

Application: Protect 12V/2A device from reversed power connector.

  • Forward voltage: ~0.3-0.5V (lower than silicon PN junction)
  • Power loss: P = Vf × I = 0.4V × 2A = 0.8W dissipation
  • Package: Choose package with adequate thermal dissipation
  • Alternative: P-channel MOSFET for lower loss (mV drop vs 400mV)

15. LED Current Limiting Resistor

Application: Drive 20mA green LED from 3.3V logic output.

  • LED Vf: ~2.1V (green), ~1.8V (red), ~3.0V (blue/white)
  • Calculation: R = (3.3V - 2.1V) / 20mA = 60Ω → use 68Ω (standard value)
  • Power: P = I²R = 0.02² × 68 = 27mW → 0402/0603 is adequate
  • Brightness control: Reduce current for dimmer LED or use PWM

16. Voltage Reference Selection for ADC

Application: 2.5V reference for 16-bit ADC with 1 LSB accuracy requirement.

  • Initial accuracy: ±0.02% (0.5mV) or better
  • Temperature coefficient: <5ppm/°C for 16-bit
  • Noise: Low-frequency noise matters for DC measurements
  • Load regulation: Must handle ADC reference current variation
Common mistake: Using LM4040 shunt reference (~100ppm/°C) for precision ADC. Use LT1009, REF3025, or LTC6655 class references instead.

17. Electrolytic Capacitor Lifetime

Application: 24/7 industrial power supply with 10-year life requirement.

  • Arrhenius rule: Life doubles for every 10°C reduction in temperature
  • Example: 2000hr @ 105°C → 16000hr @ 85°C → 128000hr @ 65°C
  • Ripple current: High ripple heats capacitor, reducing life
  • Long-life series: Nichicon UHE, Panasonic EEU-FR, Rubycon ZLH

18. Current Sense Transformer Selection

Application: Isolated AC current measurement for power meter.

  • Turns ratio: Common ratios are 1:100, 1:1000, 1:2000
  • Burden resistor: Sets output voltage scale (e.g., 100Ω for 1V/A with 1:100)
  • Accuracy class: Class 0.5 or Class 1 for energy metering
  • Saturation: Check core doesn't saturate at maximum current
