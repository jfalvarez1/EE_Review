Boost (Step-Up) Converter

The boost converter steps up voltage by storing energy in an inductor when the switch is ON and releasing it to the output when OFF. Output voltage is always higher than input.

Output Voltage
Vout = Vin / (1 − D)
Duty Cycle
D = 1 − Vin/Vout
Key Insight: The boost converter cannot disconnect the input from output—there's always a DC path through the inductor and diode. This means inrush current at startup can be high, and the output can never be less than Vin.

Boost Converter Topology

The boost stores energy in the inductor when the switch is ON, then releases it through the diode to charge the output when the switch is OFF:

Switch ON
L charges from Vin, Cout supplies load
Switch OFF
L releases via diode to Cout and load
Key Point
Input current is continuous (through L)

Boost vs Buck Comparison

Parameter Buck Boost
Voltage relationship Vout < Vin Vout > Vin
Duty cycle D = Vout/Vin D = 1 − Vin/Vout
Input current Pulsating (switch node) Continuous (through inductor)
Output current Continuous Pulsating (through diode)
Input-output isolation Switch provides isolation No isolation (DC path exists)

Practical Considerations

Maximum Duty Cycle
Controllers limit Dmax to 85-95% for stability
Startup Inrush
Add soft-start or current limit
Right-Half-Plane Zero: Boost converters have a RHP zero that limits control bandwidth. Higher duty cycles make this worse. Design control loops conservatively with gain margin.
