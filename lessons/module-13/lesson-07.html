Control Loop Fundamentals

Every switching regulator needs a control loop to maintain output voltage regulation. Understanding voltage-mode and current-mode control is essential for designing stable, responsive power supplies.

Control Loop Objectives

  • DC regulation: Maintain Vout despite load changes
  • Line rejection: Reject input voltage variations
  • Fast transient response: Recover quickly from load steps
  • Stability: No oscillation under any condition

Voltage Mode vs Current Mode Control

Power Stage Transfer Functions

Buck Converter - Voltage Mode

Gvd(s) = Vin × (1 + s/ωz) / [(s/ω0)² + s/(Q×ω0) + 1]

Where:

  • ω0 = 1/√(LC) - LC resonant frequency
  • Q = R√(C/L) - quality factor
  • ωz = 1/(ESR×C) - ESR zero

Double pole at ω0 causes −40dB/decade rolloff, requiring Type III compensation.

Buck Converter - Current Mode

Gvd(s) = Vin × Ri × (1 + s/ωz) / (1 + s/ωp)

Where:

  • ωp = 1/(R×C) - single pole from output cap and load
  • ωz = 1/(ESR×C) - ESR zero
  • Ri = current sense gain

Single pole makes compensation much simpler (Type II often sufficient).

Subharmonic Oscillation

Current mode control can oscillate at half the switching frequency if duty cycle exceeds 50% without slope compensation.

The Problem

At D > 50%, a small perturbation in inductor current grows each cycle instead of decaying. This causes alternating large/small duty cycles at fsw/2.

Slope Compensation

Add an artificial ramp to the current sense signal:

m_c ≥ 0.5 × m₂

Where m₂ is the inductor current down-slope.

This stabilizes the inner current loop for all duty cycles.
