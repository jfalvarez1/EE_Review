Multiphase and Coupled-Inductor Voltage Regulators

Design a coupled-inductor voltage regulator by specifying both its switching ripple and its response to a load step. This lesson separates interleaving, direct magnetic coupling between phases, and the trans-inductor voltage regulator (TLVR). They are related techniques with different magnetic circuits and implementation requirements.

Prerequisites: buck operation, inductor volt-second balance, current-mode control, and loop-gain measurement. Start with the multiphase VRM lesson if those are new.

1. Circuit template: two inversely coupled phases

Each power-stage block contains a high-side and low-side switch with their driver. Both stages use the same Vin and power ground. Drive PWM2 half a period after PWM1. Winding current references i1 and i2 both run from SW toward OUT; the opposite dot positions make M negative in that reference system. The dots identify winding polarity, not extra electrical connections. Cout and the load return to power ground.

For equal self-inductances L, write the winding equations before choosing a coupling factor:

\[\begin{bmatrix}v_1\\v_2\end{bmatrix}= \begin{bmatrix}L&M\\M&L\end{bmatrix} \begin{bmatrix}di_1/dt\\di_2/dt\end{bmatrix},\qquad M=\rho L,\quad |\rho|<1\]

Adding and subtracting the equations gives two modes:

\[L_{common}=L+M,\qquad L_{differential}=L-M\]

Equal winding voltages excite the common mode; opposite winding voltages excite the differential mode. Inverse coupling makes the common-mode inductance smaller. Actual PWM operation combines modes, so a winding current generally has multiple slopes within a cycle. The common-mode inductance describes a magnetic limit on current slew; it does not include controller latency.

ADI's coupled-inductor technology discussion explains the ripple/transient trade. The equations here are the explicitly defined two-winding linear model; do not apply this 2×2 matrix unchanged to N coupled windings.

Calculated example: 12 V → 1.2 V, 600 kHz per phase, Lcommon = 75 nH. With ρ = 0, each phase has 24.0 A peak-to-peak ripple. With ρ = −0.5, L = 150 nH, M = −75 nH, and the phase ripple is 15.1 A. The summed ripple is 21.3 A in both cases. Reducing winding ripple does not automatically reduce the ripple delivered to Cout.

3. Interleaving is a separate calculation

For N equal, uncoupled phase inductors with identical PWM at 360°/N spacing, normalize total ripple to one phase's ripple:

\[K(D,N)=\frac{[(m+1)-ND][ND-m]}{ND(1-D)},\quad m=\lfloor ND\rfloor,\quad 0<D<1\]

At D = 0.1, K is 0.889 for two phases, 0.222 for eight, and zero for ten in this ideal model. Exact cancellation assumes equal inductance, timing, duty, and phase spacing; parasitic switching spikes and load transients remain. Do not multiply this uncoupled K by the coupled winding's reduced ripple to predict the output.

4. Turn the concept into a design

  1. Write the rail specification. Record Vin range, Vout tolerance at the load, continuous and peak current, load-step size and edge rate, allowed droop/overshoot, switching frequency, temperature, height, and efficiency targets.
  2. Choose what stays equal in the comparison. Compare designs at equal common-mode inductance, equal phase ripple, or equal measured transient performance. Record that choice before comparing losses or capacitor count.
  3. Specify the magnetics completely. Request the winding diagram, open-circuit self-inductances, mutual terms, the test conditions and definition for any “leakage” value, DCR versus temperature, bias-dependent inductance, saturation criterion, AC loss data, and thermal limits. A catalogue's leakage value need not equal Lcommon in this lesson's model.
  4. Check current and energy limits. Use actual phase waveforms for peak and RMS current. Include imbalance, startup, current limiting, and phase shedding; equal DC winding currents cannot be assumed in a fault. Verify the magnetic manufacturer's ratings under the intended bias and temperature.
  5. Design current sensing and the loop together. A conventional single-inductor DCR network does not automatically reproduce current in a coupled winding: terminal voltage contains the other winding's derivative. Use the controller/vendor's supported sensing scheme and compensation model.
  6. Lay out and verify the complete power path. Keep input bypassing local to each half-bridge. Route sensitive current and remote-voltage sense connections away from switch nodes; include output copper and capacitor placement in the transient model.

Implementation examples: ADI's two-phase MAX8686 comparison and ADI's six-phase LT8627SP design. The latter reports a 12 V to 1 V, 2 MHz-per-phase implementation, with measured loop and transient comparisons. Its component values and compensation belong to that implementation; they are not universal defaults.

For a first capacitor estimate, use the area of the current deficit: \(\Delta V_C=\int (I_{load}-\sum i_{phase})dt/C\). Add ESR, ESL, and distribution-network contributions separately. A faster magnetic current ramp helps only after the controller responds.

5. TLVR: a secondary loop connects the phases

Two phases shown for topology clarity; a practical design may use more. Each primary/secondary pair shares a core. The secondaries connect in series through Lc; they do not connect in parallel with the output windings. Winding dots and the chosen series order determine the induced loop voltage. TI SLUP413A, Fig. 11.

Choose Lc using both ripple and transient requirements. Verify its peak circulating current, RMS loss, saturation, and decay between repeated load steps. The loop can carry substantial current even when load current is distributed across many phases.

Check secondary-loop voltage stress and routing; a low output voltage does not imply every loop node is low voltage. Use supported current sensing, compensation, phase-shedding behavior, and open/short-loop protection. TI SLUP413A, pp. 12–20.

For an example of actual magnetic specifications, see Coilcraft Doc. 1883. It distinguishes saturation-current tests from temperature-rise ratings and points to the SLV9080 and SLV1211 winding drawings. Select a part against the complete waveform and layout; the family headline current is not an operating-point guarantee.

Simulation setup. Use the two-phase schematic above. Start with prescribed SW1 and SW2 square waves and a fixed output-voltage source, so the magnetic behavior is isolated from the control loop.

Download the LTspice magnetics fixture. Open it in LTspice and run. Plot I(L1), −I(L2), and I(L1)−I(L2); L2's reversed node order sets the winding polarity. Compare its ripple with the calculated values above. The prescribed sources do not regulate average current; initial conditions set the DC offsets. Finite edge times can introduce a small difference.

  1. Compare coupling magnitudes 0, 0.5, and 0.7 at fixed Lcommon. Record phase and summed peak-to-peak currents over a settled cycle.
  2. Check the dot convention by reversing one winding in a copy of the model. Re-derive the signs before interpreting the changed waveform.
  3. Change duty cycle and phase spacing independently. Predict which switching intervals change before running the case.
  4. For a complete regulator, start from a supported vendor design. Use its controller model, power stages, magnetic model, compensation, and layout guidance.
  5. On that board, verify switching phase order, both phase currents, and voltage at the remote-sense point. Record probe configuration and bandwidth.
  6. Measure load-step droop and overshoot, loop gain, phase sharing, efficiency, and magnetic/power-stage temperatures across the specified operating range. Include phase shedding if enabled.
