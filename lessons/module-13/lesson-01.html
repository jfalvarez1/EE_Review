Decoupling & Bypass Strategy

Decoupling capacitors provide local energy storage and filter high-frequency noise from power rails. Proper selection and placement is critical for reliable operation.

Bulk Capacitor
100µF+, low frequency
Bypass Capacitor
0.1µF-10µF, mid frequency
HF Capacitor
1nF-100nF, high frequency
Key Insight: Every capacitor has self-resonant frequency (SRF). Below SRF it's capacitive; above SRF it's inductive (ESL dominates). Use multiple values to cover wide frequency range.

Placement Rules

Distance
As close to IC pins as possible
Via Count
Multiple vias reduce inductance
Layer
Same layer as IC preferred
Orientation
Short path from VCC to GND pin
Common Mistakes:
  • Placing caps far from IC (adds trace inductance)
  • Routing power through cap instead of to cap
  • Using only one capacitor value
  • Ignoring DC bias derating of MLCC
