Digital Power Control and Multi-Phase VRMs

Modern processors require high-current, fast-transient power delivery. Multi-phase voltage regulator modules (VRMs) with digital control provide the performance, efficiency, and flexibility needed for demanding applications.

Why Multi-Phase?

  • Current sharing: Split load across phases
  • Ripple cancellation: Interleaved switching
  • Thermal distribution: Spread heat across PCB
  • Fast transient: Higher effective fsw

Why Digital Control?

  • Programmable: Tune loop via software
  • Telemetry: Read V, I, T, efficiency
  • Adaptive: Load-dependent optimization
  • PMBus: Standardized communication

Multi-Phase Buck Topology

In a multi-phase buck, each phase operates at the same frequency but with a phase offset. This reduces input and output ripple while maintaining fast transient response.

Ripple Cancellation Effect

Interleaved phases partially cancel output ripple. Maximum cancellation occurs at specific duty cycles.

Number of Phases Effective Ripple Freq Zero-Ripple Duty Cycles Typical Application
1 fsw None Low power, simple
2 2 × fsw 50% GPU, mid-power CPU
4 4 × fsw 25%, 50%, 75% Desktop CPU, server
6-8 N × fsw Multiple High-end server, datacenter

Digital Control Architecture

Digital controllers sample voltage and current, compute compensation in digital domain, and generate PWM signals.

Parameter Typical Value Impact
ADC Resolution 10-12 bits Voltage regulation accuracy
ADC Sample Rate 1-10 MHz Control bandwidth, transient response
DPWM Resolution 10-14 bits Duty cycle granularity, limit cycle
Control Latency 100-500 ns Phase margin, stability
Switching Frequency 250 kHz - 1 MHz Inductor size, efficiency, EMI

PMBus Communication

PMBus (Power Management Bus) is an I²C-based protocol for controlling and monitoring power supplies.

Command Code Description
VOUT_COMMAND 0x21 Set output voltage setpoint
READ_VOUT 0x8B Read actual output voltage
READ_IOUT 0x8C Read output current
READ_TEMPERATURE 0x8D Read controller temperature
READ_POUT 0x96 Read output power
OPERATION 0x01 Turn output on/off, margin
STATUS_WORD 0x79 Fault/warning status

Popular VRM Controller ICs

  • Intel VR14: ISL69269, RAA229131
  • AMD SVI3: ISL69260, MP2971
  • Generic PMBus: LTC3889, TPS53679
  • DrMOS: Integrated driver + MOSFETs

VRM Design Specs (Typical)

  • VIN: 12V ± 5%
  • VOUT: 0.5V - 1.8V programmable
  • Accuracy: ± 0.5%
  • Transient: ± 3% for 100A step
