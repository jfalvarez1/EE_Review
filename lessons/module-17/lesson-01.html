DAC Fundamentals

Digital-to-Analog Converters translate binary codes into analog voltages or currents. Understanding resolution, linearity, and settling time is essential for analog interface design.

Resolution
LSB = Vref / 2N
Dynamic Range
DR = 6.02×N + 1.76 dB
Key Insight: A 12-bit DAC has 4096 steps. With 2.5V reference, each LSB is 610µV. But DNL and INL errors often exceed 1 LSB, limiting actual accuracy to 10-11 bits.

DAC Architectures

Architecture Speed Resolution Notes
R-2R Ladder Medium 8-16 bit Simple, needs matched resistors
Binary Weighted Fast 8-12 bit Glitches at major transitions
Sigma-Delta Slow 16-24 bit Oversampling, excellent linearity
Current Steering Very Fast 10-16 bit Video/RF, 100MHz+ update

Key Specifications

DNL
Differential Non-Linearity: step size error
INL
Integral Non-Linearity: cumulative error
Settling Time
Time to reach final value (±1 LSB)
Glitch Energy
Spurious energy during transitions
