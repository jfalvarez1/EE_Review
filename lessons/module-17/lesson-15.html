Monotonicity in Data Converters

Monotonicity is a fundamental characteristic that determines whether a converter's output consistently follows its input direction. Non-monotonic behavior can cause catastrophic failures in control systems.

Monotonic DAC
Output always ↑ when code ↑
Monotonic ADC
Code always ↑ when input ↑
Critical Threshold
DNL ≥ -1 LSB
Key Insight: A converter is monotonic if and only if its Differential Nonlinearity (DNL) never drops below -1 LSB. When DNL < -1 LSB at any transition, the output reverses direction briefly, creating non-monotonic behavior. This is a binary characteristic—a converter is either monotonic or it isn't.

What Causes Non-Monotonic Behavior?

Root Cause: Differential Nonlinearity (DNL) Exceeding -1 LSB

Physical Causes by Architecture

R-2R Ladder DAC
  • Resistor mismatch between R and 2R values
  • MSB resistor has 8× more influence than LSB
  • Temperature drift causes ratio tracking errors
  • Need <0.05% tolerance for 12-bit monotonicity

Most vulnerable: Major carry transitions (0111→1000)

SAR ADC
  • Capacitor DAC mismatch (unit cap variations)
  • Comparator offset and metastability
  • Incomplete settling during acquisition
  • High source impedance + parasitic capacitance

Signature: Repetitive 2k DNL spikes in histogram

Sigma-Delta ADC
  • Inherently monotonic by architecture
  • Oversampling + noise shaping averages errors
  • Multi-bit modulators need DEM (Dynamic Element Matching)

Preferred for control applications requiring guaranteed monotonicity

Why Monotonicity Matters: Control Loop Stability

Application Monotonicity Required? Consequence of Non-Monotonicity
Motor servo control CRITICAL Motor jerks, oscillates, or reverses direction
PID temperature control CRITICAL Heater cycles unstably, overshoots
Power supply regulation CRITICAL Output voltage oscillates, potential damage
Audio playback Important Audible distortion, especially at low levels
Data logging Preferred Non-monotonic steps appear as noise in data
Video display Preferred Visible banding or artifacts at transitions
Control Loop Oscillation Mechanism:

In a feedback control system, the controller adjusts output to minimize error. If the ADC or DAC has a non-monotonic region:
  1. System approaches setpoint from one direction
  2. At non-monotonic transition, output REVERSES despite input continuing
  3. Controller sees error suddenly increase in wrong direction
  4. Controller overcorrects, pushing past the non-monotonic region
  5. System oscillates around the non-monotonic code

This effectively converts negative feedback to positive feedback at that operating point!
