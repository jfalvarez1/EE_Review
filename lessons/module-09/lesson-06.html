PLL Fundamentals

Phase-Locked Loops (PLLs) are fundamental building blocks for frequency synthesis, clock recovery, and demodulation. This lesson covers the basic PLL architecture, loop components, and stability considerations.

PLL Components

  • Phase Detector: Compares phases
  • Loop Filter: Controls bandwidth
  • VCO: Generates output freq
  • Divider: Frequency synthesis

Key Parameters

  • Lock Range: Tracking bandwidth
  • Capture Range: Acquisition range
  • Phase Noise: Output jitter
  • Loop BW: Filter cutoff
