Scenario: IoT Sensor Node Design

Design a battery-powered temperature/humidity sensor that runs for 2+ years on a coin cell, with wireless transmission every 10 minutes.

Battery
CR2032 (220mAh)
Target Life
2 years minimum
Wireless
BLE / LoRa / Zigbee
Key Challenge: At 220mAh capacity and 2-year target, average current must be below 12.5µA. The MCU and radio consume milliamps when active, so aggressive duty cycling is essential.

Design Decisions

Decision Option A Option B Recommendation
Power regulation LDO (stable VCC) Direct battery Direct if MCU handles 2-3V range
Sensor power Always on Load switch Load switch if sensor Iq > 1µA
Wireless BLE (short range) LoRa (long range) BLE for home, LoRa for outdoor
Crystal 32kHz XTAL Internal RC RC saves power, XTAL for timing
Hidden Current Drains:
  • Pull-up resistors on unused I2C bus: 3.3V/10kΩ = 330µA (!)
  • Status LEDs: 1-10mA if left on
  • Voltage dividers for battery monitoring
  • MCU pins not configured (floating inputs)
