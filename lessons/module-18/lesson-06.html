Flyback Design Equations

Turns Ratio:
    n = Np/Ns = (Vin × D) / (Vout × (1-D))

    For CCM with D_max = 0.45:
    n = Vin_min × 0.45 / (Vout × 0.55)

Duty Cycle (CCM):
    D = (n × Vout) / (Vin + n × Vout)

Primary Inductance (CCM):
    Lpri = (Vin_min × D_max)² / (2 × fsw × Pout × K)
    K = ripple factor (typ 0.4)

Primary Peak Current:
    Ip_pk = (Pout / (η × Vin)) × (1 + K/2) / D

Switch Voltage Stress:
    Vsw = Vin + n × (Vout + Vf) + Vspike
    Vspike from leakage inductance!

Output Diode Stress:
    Vd = Vout + Vin/n

Snubber Design:
    Leakage energy: E = 0.5 × Llk × Ip²
    Snubber cap: Cs > Llk × Ip² / Vclamp²
    Snubber resistor: Rs = Vclamp² / (fsw × E)
