Power Sequencing Design

Modern systems require multiple voltage rails to power up and down in specific order. Learn sequencing strategies, timing requirements, and implementation methods to prevent damage and ensure reliable operation.

Critical: Check IC datasheets for power sequencing requirements. Violating sequence order can cause latch-up, excess current, or permanent damage. FPGA, CPU, and DDR memory are particularly sensitive.

Common Sequencing Requirements

Device Type Typical Requirement Reason
FPGA Vccint → Vccaux → Vcco Core first, then I/O, prevents latch-up
DDR Memory VDD → VDDQ → VTT Core stable before I/O, termination last
CPU/SoC Core → I/O → Peripherals Internal regulators need stable input
High-speed SerDes AVDD → DVDD → VTT PLL stability before digital
Op-amps (±supply) ±V simultaneous or V+ first Prevent output swing to rail
Mixed-signal Analog → Digital Stable reference before ADC/DAC
