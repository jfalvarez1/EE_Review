PCB Layout for EMC

PCB layout is often the determining factor in EMC performance. Proper grounding, decoupling, trace routing, and layer stack-up can mean the difference between a product that passes EMC testing on the first attempt and one requiring costly redesigns.

Goal:Minimize loop areas and control return currents
Key Concept:Current always returns - control where
Stack-up:Use continuous ground planes
Decoupling:Place caps at IC pins, minimize loop
EMC Golden Rule: Every signal has a return current. If you don't provide a low-impedance path for that return current, it will find its own path - usually creating a large radiating loop.

Layer Stack-up Strategies

4-Layer Stack-up (Most Common)

Layer 1: Signals (components)
Layer 2: Ground Plane
Layer 3: Power Plane
Layer 4: Signals (bottom)

Advantages: Good for most designs
- Signal-ground spacing ~10 mil
- Controlled impedance possible
- Return current directly below signals

6-Layer Stack-up (High Performance)

Layer 1: Signals
Layer 2: Ground Plane
Layer 3: Signals (inner)
Layer 4: Power Plane
Layer 5: Ground Plane
Layer 6: Signals

Advantages: Better isolation
- Multiple ground references
- Inner signal layers shielded
Signal-to-Ground:Adjacent layers for low inductance return
Power-Ground:Tight coupling for plane capacitance
High-Speed:Route on outer layers with ground below

Decoupling Best Practices

Placement Rules

  • Place capacitors as close to IC power pins as possible
  • Connect directly to power and ground pins (shortest path)
  • Use multiple vias to planes for lower inductance
  • Smaller packages (0402, 0201) have lower ESL

Capacitor Value Selection

Bulk (10-100 μF):Low frequency, voltage transients
Mid (0.1-1 μF):General purpose, 1-50 MHz
Small (10-100 nF):High frequency, 50-500 MHz
Tiny (100 pF-1 nF):Very high frequency, >500 MHz

Via Inductance

L_via ≈ 5.08h × (ln(4h/d) + 1) [nH]

where h = via height (in), d = via diameter (in)

Typical 1mm thick board, 0.3mm via: ~1 nH per via

Trace Routing Guidelines

High-Speed Signal Routing

  • Route over continuous ground plane (no splits)
  • Avoid crossing plane gaps - forces return current detour
  • Maintain constant impedance (controlled impedance traces)
  • Use length matching for differential pairs
  • Avoid right-angle bends (use 45° or arcs)

Return Current Path

At high frequencies, return current flows directly beneath the signal trace due to inductance minimization. Plane gaps interrupt this path.

<1 MHz:Returns via lowest resistance path
>1 MHz:Returns directly below signal trace
Plane gap:Creates slot antenna, radiates

Layer Changes

When a signal changes layers, add ground vias adjacent to signal via to provide return current path.

Component Placement for EMC

General Principles

  • Place high-frequency circuits near connectors (minimize trace antenna length)
  • Keep analog and digital sections separate
  • Place oscillators/clocks away from board edges and I/O
  • Orient switching regulators to minimize coupling to sensitive circuits
  • Use guard traces around sensitive analog signals

Zoning Approach

Common EMC Layout Mistakes

MistakeProblemSolution
Split ground planeLarge return current loopsUse solid ground, connect at one point if needed
Long decoupling tracesHigh inductance, ineffectiveMinimize trace length, use multiple vias
Clock routed to edgeActs as antennaKeep clocks internal, use spread spectrum
No ground via at layer changeReturn current detoursAdd ground via adjacent to signal via
Power/ground plane gapSlot antenna radiationBridge with capacitors or solid copper
Unfiltered I/OConducted emissionsFilter at connector boundary
