Case Study: RF Interference Investigation

Investigate mysterious intermittent behavior in a mixed-signal system caused by RF interference. This scenario covers EMI debugging techniques, spectrum analysis, and implementing effective countermeasures.

Symptom
ADC readings jump randomly
When
Intermittent, varies by location
Equipment

Industrial facility
Key Clue: "Varies by location" and "intermittent" strongly suggest external RF interference. The first step is characterizing the RF environment with a spectrum analyzer or SDR.

The Scenario

System: 16-bit precision temperature measurement system

  • ADC: 16-bit SAR, 100kSPS
  • Sensor: RTD with signal conditioning
  • Communication: SPI to microcontroller
  • Problem: Random spikes of ±50 counts (~0.04°C)
  • Observation: Worse near certain equipment
  • Clue: Walkie-talkies used in facility (VHF 150MHz)

Investigation Process

Root Cause Analysis

Finding: RTD sensor cable acting as antenna at 150MHz.

  • Spectrum analyzer shows 150MHz signal at -30dBm on cable
  • λ/4 at 150MHz = 0.5m, cable is 2m (multiple λ/4)
  • RF rectified by ADC input protection diodes
  • Rectified DC causes offset shifts proportional to RF power

Solution:

  1. Add ferrite bead (FB) on cable near ADC input
  2. Add 100pF capacitor across ADC input
  3. Shield sensor cable with grounded braid
  4. Result: Error reduced from 50 counts to <2 counts
