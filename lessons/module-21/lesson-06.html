RF Matching Networks

Impedance matching is fundamental to RF design. Maximum power transfer occurs when the source impedance equals the complex conjugate of the load impedance. Matching networks transform impedances using reactive elements (L, C) or transmission line techniques. This lesson covers the design of L-networks, Pi-networks, and T-networks.

Standard Z₀50Ω (RF systems)
Match GoalVSWR < 1.5:1
Network TypesL, Pi, T, Transmission Line
Key ParameterS11 (Return Loss)
Maximum Power Transfer: For complex impedances Z_S = R_S + jX_S and Z_L = R_L + jX_L, maximum power transfer requires Z_L = Z_S* (conjugate match). Return loss RL = -20×log₁₀|Γ| where Γ = (Z_L - Z_S)/(Z_L + Z_S).

Component Considerations

Frequency Preferred Components Considerations
< 100 MHz Discrete L, C Use high-Q inductors (air core, powdered iron)
100 MHz - 1 GHz SMD 0402/0201, wire inductors Watch for self-resonance, parasitic C
1 - 6 GHz 0201 SMD, microstrip SRF critical, transmission line stubs
> 6 GHz Distributed elements only Microstrip, stripline, CPW
Self-Resonant Frequency (SRF): All inductors have parasitic capacitance that causes self-resonance. Use components with SRF > 3× operating frequency. At SRF, the inductor becomes an open circuit.
