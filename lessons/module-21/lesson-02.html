Low Noise Amplifiers (LNA)

Low Noise Amplifiers are critical front-end components in receivers, designed to amplify weak signals while adding minimal noise. The LNA's noise figure largely determines the system's overall sensitivity, making proper design essential for RF applications.

Purpose:Amplify weak RF signals with minimal noise addition
Key Metric:Noise Figure (NF) - typically 0.5-3 dB
Gain Range:10-25 dB typical
Placement:First stage after antenna/filter
Friis Formula: The first amplifier dominates system noise figure. An LNA with 1 dB NF and 20 dB gain makes second-stage noise contribution nearly negligible.

Noise Figure Fundamentals

Noise figure quantifies how much noise an amplifier adds to a signal, expressed as the degradation in signal-to-noise ratio from input to output.

Noise Factor (F): F = SNR_in / SNR_out

Noise Figure: NF = 10 × log₁₀(F) [dB]

Noise Temperature: T_e = T₀ × (F - 1), where T₀ = 290K

Friis Cascade Formula

F_total = F₁ + (F₂-1)/G₁ + (F₃-1)/(G₁×G₂) + ...

Thermal Noise:-174 dBm/Hz at 290K
Shot Noise:i² = 2qI_DC × BW
Flicker (1/f):Significant below 10 kHz

LNA Topologies

1. Common Source/Emitter with Inductive Degeneration

Most popular topology - provides simultaneous noise and power match through source inductance.

  • Source inductor (L_s) creates real input impedance
  • Gate inductor (L_g) resonates with C_gs for matching
  • Achieves near-minimum noise figure with 50Ω match

2. Cascode Configuration

Common source + common gate provides improved reverse isolation and reduced Miller effect.

  • Higher gain and better stability
  • Reduced Miller capacitance improves bandwidth
  • Slightly higher noise than single-stage

3. Common Gate

Wideband input match but higher noise figure.

  • Intrinsic 50Ω input impedance (when gm = 1/50)
  • NF ≈ 2-3 dB minimum for single transistor
  • Good for wideband applications

4. Noise-Canceling LNA

Uses auxiliary path to cancel noise from input matching device.

  • Achieves sub-1 dB NF in CMOS
  • Wideband operation possible
  • Higher power consumption
