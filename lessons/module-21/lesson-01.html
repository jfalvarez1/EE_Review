RF Matching Networks

A matching network transforms the impedance seen by a source. Start with the impedances at the intended frequency and operating condition; then choose a topology, calculate a starting point, and measure the assembled board.

Two different conditions. Maximum available power transfer from a linear source requires a conjugate match, Zin = ZS*. For reflection relative to a real port reference Z₀, use Γ = (Zin − Z₀)/(Zin + Z₀) and return loss = −20 log₁₀|Γ|. An RF power amplifier’s optimum load or an LNA’s minimum-noise match can differ from a power match.

References: ADI: Impedance Matching and Smith Chart Impedance; TI SLAA525, §2 and measured examples in §§3–4.

These circuits match a resistive load larger than the source resistance. The shunt element belongs on the higher-resistance side. The voltage source and its series resistance are explicit; each ground symbol is the same return node.

Low-pass: series inductor, shunt capacitor

High-pass: series capacitor, shunt inductor

RH = max(RS, RL), Rlo = min(RS, RL)
Q = √(RH/Rlo − 1)
|Xseries| = Q Rlo, |Xshunt| = RH/Q
L = XL/(2πf₀), C = 1/(2πf₀|XC|)

At f₀, the shunt reactance transforms the high resistance; the series reactance cancels the remaining imaginary part. Equal resistances need no reactive transformation in this model. Low-pass and high-pass describe the network response, not a guaranteed rejection specification.

Transmission-line matching

Quarter-wave transformer

A lossless line of electrical length 90° transforms a real load to Zin = Zt²/RL. Choose Zt = √(RSRL) at f₀. Physical length is vp/(4f₀); obtain phase velocity from the actual line geometry and dielectric model. Microstrip uses effective permittivity, which is not simply the laminate’s bulk εr.

Shunt short-circuited stub

Move along the main line to a point whose normalized admittance has conductance 1, then choose stub susceptance to cancel the imaginary part. The drawn stub is shorted at its far end. An open stub is a different termination and requires a different length.

For line transformations and graphical matching, see ADI’s Smith chart tutorial. Use your PCB/RF simulator’s line model to calculate electrical length.

  1. Simulate. Build this circuit in Circuit Toy or a simulator with AC analysis. Sweep 100 MHz–1 GHz. Compute Zin = V(node1)/I(L1), with I(L1) positive from node1 to node2. Convert to Γ using Z₀ = 50 Ω. Rs is outside this measurement plane.
  2. Use real models. Substitute manufacturer RF models. Include pads, ground vias and interconnect; compare the match and insertion loss.
  3. Measure. Use a PCB fixture with a 150 Ω RF termination. Calibrate/de-embed a 50 Ω VNA to node1 and record S11 before and after populating the network. The VNA supplies the source impedance; do not add a second 50 Ω series source resistor on this fixture.
  4. Tune and explain. Change one part, remeasure center frequency and usable band, and compare with the model. Record calibration plane, fixture, part numbers and return-loss requirement.

Component and layout decisions

  • Check impedance, Q, tolerance, ratings and self-resonance at the operating frequency using the selected part’s data. Self-resonance produces a finite lossy impedance, not a perfect open circuit.
  • Keep the reference plane and return path explicit. Pad capacitance and via inductance can matter relative to a few picofarads or nanohenries.
  • Verify the operating band and system objective: loss, noise figure, linearity or power handling may constrain the match. Package size and frequency alone do not determine whether lumped or distributed matching is appropriate.

Practice exercises

Match 50 Ω to 200 Ω at 915 MHz with a low-pass L network.

Q = √3 = 1.732. Series reactance = 86.60 Ω; shunt reactance magnitude = 115.47 Ω. L = 15.06 nH and C = 1.506 pF. The shunt capacitor is across the 200 Ω load. Determine bandwidth against a stated return-loss threshold.

What changes if source and load are swapped?

The ideal component values stay the same; the shunt capacitor moves to the input of the matching network, on the 200 Ω side. The series inductor connects this node to the 50 Ω load. Retain the actual source and load labels.

A load has VSWR 2.5:1. How much incident power is reflected?

|Γ| = 0.4286. Reflected fraction = |Γ|² = 18.37%; return loss = 7.36 dB. For 1 W incident at the load plane, 0.816 W is accepted. Accepted antenna power is not necessarily radiated power.
