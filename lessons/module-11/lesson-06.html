Reference Formulas

Linear Regulator: Pdiss = (Vin - Vout) × Iload

Buck Duty Cycle: D = Vout / Vin

Boost Duty Cycle: D = 1 - Vin / Vout

Buck Inductor: L = Vout(1-D) / (ΔIL × fsw)

Output Ripple: ΔV = ΔIL / (8 × fsw × Cout)

Thermal: Tj = Ta + Pdiss × θJA
