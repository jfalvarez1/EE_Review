Cost vs Performance Trade-offs

Component cost scales with precision, speed, and power handling. Production designs must balance performance requirements against BOM (Bill of Materials) cost targets.

Precision Resistors
0.1%: $0.10 vs 1%: $0.01
Op-Amp Range

Key Insight: Often you can achieve the same system performance with clever topology rather than expensive components. Calibration can compensate for component tolerance if you have an MCU.

Cost Reduction Strategies

Strategy Cost Savings Trade-off
Digital calibration Use cheaper components Adds MCU, firmware, test time
Ratiometric design Cancels reference errors Requires matched ratios
Chopper stabilization Eliminates offset trim Adds noise at chop frequency
Integration Replace discretes with IC Less flexibility
Value engineering Optimize every component Engineering time

When to Spend More

Safety Critical
Medical, automotive—failure cost >> component cost
Low Volume
NRE dominates, component cost less important
Competitive Edge
Premium performance commands premium price
Hidden Costs: Cheap components may require more testing, calibration, or have higher failure rates. Total cost of ownership matters more than BOM cost.
