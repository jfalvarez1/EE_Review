Watchdog Timers

Watchdog timers (WDT) are critical safety components that detect software hangs and trigger system recovery. This lesson covers watchdog architectures, windowed operation, and proper implementation.

Watchdog Functions

  • Timeout detection: Software hasn't kicked
  • System reset: Force restart
  • Interrupt: Warning before reset
  • Window mode: Detect too-fast kicks

Implementation Types

  • Internal: MCU peripheral
  • External: Dedicated IC
  • Windowed: Min and max time
  • Independent: Separate oscillator
