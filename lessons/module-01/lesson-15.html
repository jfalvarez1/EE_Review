Current Feedback Amplifiers (CFAs)

Current feedback amplifiers offer a different architecture than traditional voltage feedback amplifiers (VFAs). Their unique topology provides bandwidth that is nearly independent of closed-loop gain, making them ideal for wideband applications like video drivers and RF IF stages.

The Critical Insight

In a CFA, RF sets the bandwidth, not the gain. The datasheet specifies an optimal RF value (typically 500Ω-1.5kΩ). Deviating from this value affects bandwidth and stability:

  • RF too small: Potential oscillation (too much bandwidth)
  • RF too large: Reduced bandwidth, sluggish response

2. Using with Integrator Configurations

CFAs are NOT suitable for integrator or differentiator circuits. The low inverting input impedance interacts with the reactive feedback element, causing instability or incorrect behavior.

3. Input Current at Inverting Node

Unlike VFAs, the inverting input of a CFA sinks/sources significant current (error current). Source impedances driving this node should be low to avoid distortion.
