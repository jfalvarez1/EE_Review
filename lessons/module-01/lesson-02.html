Golden Rules and Basic Configurations

The operational amplifier with negative feedback follows two simple rules that make circuit analysis remarkably easy. These rules are valid when: negative feedback is applied, the op-amp is in its linear region, and the signal frequency is below the bandwidth.

Rule I
Inputs draw no current (infinite Zin)
Rule II
V+ = V− (with negative feedback)
Key Insight: These rules only apply with negative feedback! Without feedback, or with positive feedback, the op-amp saturates and the rules don't hold.

Circuit Topologies: The Four Basic Configurations

These four configurations form the foundation of almost all op-amp circuits:

Inverting: G = −Rf/R1

Non-Inverting: G = 1 + Rf/R1

Summing: Vout = −Rf(V1/R1 + V2/R2)

Difference: Vout = (Rf/R1)(V2−V1)

Virtual Ground Concept

The "virtual ground" is one of the most powerful concepts in op-amp analysis. It only exists in the inverting configuration:

Drag \(R_1\) and \(R_f\) to anything you like. Which readout never changes?

  1. The current through \(R_f\)
    It changes with everything — it equals \(V_{in}/R_1\), so both the input and \(R_1\) move it.
  2. The voltage at the − input
    Right, and it is the whole idea. Whatever you do to the resistors or the input, the op-amp moves its output until the two inputs are equal — and the + input is tied to ground, so the − input sits at 0 V. It is held there rather than connected there, which is why it is called virtual. Break the feedback loop and it stops being 0 V immediately.
  3. The gain
    The gain is \(-R_f/R_1\), so it changes the moment you move either resistor. It is independent of the input, which is a different and also useful fact.
  4. The output voltage
    The output is the one thing that has to move. Holding the − input at 0 V is precisely what the output is for.

Because that node sits at 0 V, the current into it is \(V_{in}/R_1\) and nothing else — the rest of the circuit cannot affect it. That is what makes a summing amplifier possible: several inputs can share the node without interacting, because none of them can move it.

Why "Virtual"?
The − input is held at 0V by feedback, not by a physical ground connection
Consequence
Current through R1 = Current through Rf (none enters op-amp)
Virtual Ground Derivation:
Since V+ = 0V (tied to ground) and V+ = V− (feedback rule), then V− = 0V.
This makes analysis easy: IR1 = Vin/R1 and IRf = (Vout − 0)/Rf
Since IR1 = IRf: Vin/R1 = −Vout/Rf → G = −Rf/R1

Feedback Equations

Understanding the feedback loop is key to op-amp design:

Closed-Loop Gain
GCL = A/(1+Aβ) ≈ 1/β when Aβ >> 1
Loop Gain
Aβ = AOL × (feedback fraction)

The feedback factor β determines how much of the output is fed back to the input:

Configuration β (Feedback Factor) 1/β (Noise Gain)
Inverting R1/(R1+Rf) 1 + Rf/R1
Non-Inverting R1/(R1+Rf) 1 + Rf/R1
Important: The noise gain (1/β) determines stability and bandwidth, not the signal gain! An inverting amp with gain −10 has the same noise gain (11) as a non-inverting amp with gain +11.
