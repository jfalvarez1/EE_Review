Common-Base Amplifier

The common-base configuration offers low input impedance, high output impedance, and excellent high-frequency response. It's essential for RF applications and cascode circuits.

Key Insight: Current gain ≈ 1 (α), but voltage gain can be very high. No Miller effect means excellent bandwidth. The base acts as a "shield" between input and output.

Why Common-Base for High Frequency?

Common-Emitter Problem

Miller effect multiplies Cbc by (1 + Av):

Cin = Cbe + Cbc(1 + gmRC)

For Av = 100, Cbc = 2pF becomes 200pF at input!

Common-Base Solution

Base is grounded (AC) - no Miller multiplication:

Cin = Cbe only

Input capacitance is just Cbe. Much higher fT operation!

CB bandwidth: f-3dB ≈ fT (can approach transistor's transition frequency)

CE bandwidth: f-3dB ≈ fT / Av (much lower due to Miller effect)

The Cascode: Best of Both Worlds

Combining CE (for high input Z) with CB (for high bandwidth) creates the cascode - a high-gain, high-bandwidth amplifier:

Input Z
High (CE stage)
Output Z
Very High (CB stage)
Gain
Av = gm × RC
Bandwidth
Excellent (no Miller)
How it works: Q1 (CE) sees a load of re' of Q2 (very low), so its voltage gain ≈ 1. This eliminates Miller multiplication! Q2 (CB) provides all the voltage gain with no Miller effect.

Common-Base for Current Sensing

The low input impedance makes CB ideal for current-to-voltage conversion:

Transimpedance: Vout/Iin = RC (current gain ≈ 1)

Advantage: Low input impedance minimizes voltage burden on current source

Bandwidth: Much higher than op-amp TIA for same gain

RF Amplifier Applications

50Ω Input Match

Set IE to give re' = 50Ω: IE = 26mV/50Ω = 0.52mA. Or use emitter degeneration.

Grounded-Base LNA

Low noise figure at high frequencies. Base grounded minimizes noise coupling.

Mixer First Stage

High isolation between input and output. Reduces LO feedthrough.

Video Amplifier

Wide bandwidth for video signals. Often cascoded for additional gain.

Output Impedance and Early Effect

The CB configuration has extremely high output impedance due to the Early effect boosting:

Intrinsic output resistance: ro = VA / IC (where VA = Early voltage)

CB output impedance: Zout ≈ ro × (1 + gm×Rs) where Rs is source impedance

With Rs = re' and gm×re' = 1: Zout ≈ 2×ro

Practical Biasing for Common-Base

Key Points:
  • Base is AC grounded via bypass capacitor CB
  • DC bias sets IC (and thus re' and Zin)
  • Input coupling capacitor blocks DC from source
  • RE provides DC bias path and some AC feedback
