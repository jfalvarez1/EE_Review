Op-Amp Stability and Compensation

An op-amp circuit can oscillate if the feedback loop has too much phase shift at frequencies where the loop gain is still above unity. Understanding stability analysis and compensation techniques is essential for reliable analog design.

Follow the negative-feedback loop

Define loop gain as \(L(s)=A(s)\beta(s)\), with the minus sign at the summing node shown explicitly. The closed-loop denominator is \(1+L(s)\); the critical point is therefore \(L=-1\):

\(|L|=1\quad\text{and}\quad\angle L=-180^\circ\)

This is the oscillation boundary for the simple linear feedback model. It is not a guarantee of a sustained oscillation: startup, other poles, and nonlinear amplitude limiting matter. Do not add another 180° just because the signal amplifier is inverting. TI Precision Labs: phase margin.

The summing node forms \(e=V_{in}-\beta V_{out}\). With \(V_{out}=Ae\), \(V_{out}/V_{in}=A/(1+A\beta)\). The loop-gain expression is a definition, not an extra block in the return wire.

Phase Margin and Gain Margin

Definitions

  • Phase Margin (PM): How much additional phase lag would cause oscillation at the unity-gain crossover frequency. PM = 180° + phase at |Aβ| = 1.
  • Gain Margin (GM): How much additional gain would cause oscillation when phase = -180°. GM = 1/|Aβ| when phase = -180°.

Rule of thumb: PM ≥ 45° and GM ≥ 6dB for stable operation

Sources of Excess Phase Shift

1. Capacitive Loading

Small-signal model. Rout represents the amplifier's open-loop output resistance, not a resistor to add to the board. Together with CL it contributes a pole near \(1/(2\pi R_{out}C_L)\) in this simplified model. Feedback senses out, so this loading affects the loop. Real output impedance can depend on frequency. ADI: Op Amps Driving Capacitive Loads.

2. Input Capacitance in Feedback

With the independent input source set to zero, \(\beta(s)=\frac{R_1}{R_1+R_F}\frac{1}{1+s(R_1\parallel R_F)C_{in}}\). Cin introduces a pole in β and a zero in noise gain 1/β at the same frequency, \(1/[2\pi(R_1\parallel R_F)C_{in}]\). Cin includes the input and board capacitance represented by this model. TI SLYT087, Eq. 2.

Compensation Techniques

1. Series Resistor for Capacitive Load

Build distinction: connect feedback to amp_out, before Riso. Probe both amp_out and load_out when checking the small-signal step response. The load voltage can differ because current flows through Riso. Choose Riso using the amplifier's capacitive-load guidance and verify it with your load; no single resistance range fits every op-amp. ADI, out-of-loop compensation.

2. Feedback Capacitor to Shape the Noise Gain

For the circuit shown, \(\beta(s)=\frac{R_1}{R_1+R_F}\frac{1+sR_FC_F}{1+s(R_1\parallel R_F)(C_{in}+C_F)}\). Cf adds a zero in β at \(1/(2\pi R_FC_F)\), while also changing the pole. Matching \(R_FC_F=R_1C_{in}\) cancels this modeled pole/zero pair; it does not cancel every pole inside the amplifier. Check the resulting loop and signal bandwidth. TI SLYT087, Eq. 4.

Noise Gain vs Signal Gain

Stability is determined by noise gain, not signal gain:

For an ideal op-amp with these resistive impedances, signal gain is \(-R_F/R_1\), while noise gain is \(1/\beta=1+R_F/R_1\). Estimate bandwidth as GBW/noise gain only in the dominant-pole region. For example, R1 = 10 kΩ and Rf = 100 kΩ give signal gain −10 and noise gain 11. TI SLYT087, Eq. 1 and Fig. 1.

Unity Gain is the Worst Case

With a resistive feedback network and the same voltage-feedback op-amp, lower noise gain usually puts crossover at a higher frequency, where additional poles can reduce phase margin. Raising noise gain can help in that model; capacitive feedback, loading, or a different amplifier architecture can change the result.

Decompensated Op-Amps

Some op-amps are "decompensated" to achieve higher slew rate and bandwidth. They are stable only above a minimum gain.

Op-Amp Min Stable Gain GBW Slew Rate
OP27 (compensated) 1 8 MHz 2.8 V/µs
OP37 (decompensated) 5 63 MHz 17 V/µs
AD8099 (decompensated) 2 3.8 GHz 1350 V/µs
LT1028 (compensated) 1 75 MHz 15 V/µs

Warning

Using a decompensated op-amp at a gain below its minimum stable gain will cause oscillation. Always check the datasheet!
