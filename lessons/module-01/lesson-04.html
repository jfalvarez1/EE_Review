Current Mirrors

Current mirrors replicate a reference current to one or more outputs. They are fundamental to analog IC design, used for biasing, active loads, and current sources in diff pairs.

Basic Principle
Iout = Iref × (W/L)out/(W/L)ref
For Matched BJTs
Iout ≈ Iref
Key Insight: The diode-connected transistor (Q1) forces VBE to match the current. Since Q2 shares the same VBE, it copies the current (assuming matched transistors).

The Early Effect

The simple mirror's main limitation is the Early effect—collector current varies with VCE:

With Early Effect
IC = IS × eVBE/VT × (1 + VCE/VA)
Output Resistance
ro = VA/IC

For Iref = 100µA and VA = 100V: ro = 100V/100µA = 1MΩ

This means Iout varies ~1% per volt of VCE change—problematic for precision circuits.

Wilson Mirror: The Clever Fix

The Wilson mirror uses negative feedback to boost output impedance and compensate for base current error. Refer to the schematic above for the topology.

Q3 senses the output current and adjusts Q1's VBE via feedback, keeping Iout = Iref even as Vout varies. The feedback loop provides β2 improvement in base current error.

Beta Error Analysis: Why Wilson Wins

Base current error is a significant accuracy limitation in BJT current mirrors. Let's analyze each topology:

Simple Mirror β Error

The reference current splits between Q1's collector and the base currents of Q1 and Q2:
Iref = IC1 + IB1 + IB2 = IC1 × (1 + 2/β)
∴ Iout = Iref × β/(β + 2) ≈ Iref × (1 - 2/β)

For β = 100, the simple mirror has ~2% error just from base current.

Wilson Mirror β Compensation

Wilson's feedback loop forces Q3's collector current to equal Q1's, canceling base current errors:
  • IC3 = Iout (both go to output)
  • IC3 supplies IB1 + IB2, so IC1 = Iref - IB3
  • Since IB3 = Iout/β, error reduces to 1/β² terms
Iout ≈ Iref × (1 - 2/β²)

For β = 100, Wilson's error drops to ~0.02% — a 100× improvement!

Design Guidelines (Art of Electronics)

Design Goal Recommended Topology Reason
Maximum headroom (low VCC) Simple mirror Only needs VCEsat ≈ 0.2-0.3V
Highest output impedance Cascode or Wilson Both achieve β×ro
Best current accuracy Wilson mirror β² error compensation
Diff pair active load Simple or Cascode Wilson adds unwanted phase shift
Temperature stability Add emitter degeneration RE reduces VBE sensitivity
Wilson Gotcha: The Wilson mirror has an extra pole from Q3's base, which can cause stability issues when used as an active load in high-frequency amplifiers. For diff pair active loads, prefer simple or cascode mirrors.
