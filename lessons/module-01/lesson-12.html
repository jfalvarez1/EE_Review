Voltage References with Op-Amps

While dedicated voltage reference ICs exist, op-amps are often used to buffer, scale, and filter reference voltages. Understanding how to properly interface op-amps with references is critical for precision analog design.

Reference Voltage Architectures

Bandgap References

The most common precision references are based on the bandgap voltage of silicon (~1.2V):

  • 2-terminal shunt: LM385, TL431 (operate like Zener diodes)
  • 3-terminal series: REF02, LM4040 (regulator-style output)
  • Precision ICs: ADR4550, LTC6655 (ultra-low drift)

Buffering a Reference

Many references have limited output current capability. An op-amp buffer provides current drive without loading the reference.

Op-Amp Selection for Reference Buffering

  • Low VOS: Adds directly to reference error
  • Low IB: Prevents loading the reference
  • Low noise: Don't degrade the reference's inherent noise
  • Low drift: Match or exceed reference tempco

Resistor Matching

For precision scaling, use matched resistor pairs or resistor networks. A 0.1% divider requires each resistor to be better than 0.05% (they don't add directly due to ratio).

Noise Filtering

References can have significant noise that must be filtered before use in precision circuits.
