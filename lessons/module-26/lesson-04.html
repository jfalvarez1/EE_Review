Symmetrical Components and Fault Analysis

Most faults are unbalanced — a single conductor to ground, two conductors touching. An unbalanced three-phase network does not decouple, so you cannot analyse one phase and multiply by three. Fortescue's transform fixes this: any unbalanced set of three phasors decomposes into three balanced sets, each of which can be solved on its own network.

The transform

V0 = (Va + Vb + Vc)/3   ← zero sequence
V1 = (Va + aVb + a²Vc)/3   ← positive sequence
V2 = (Va + a²Vb + aVc)/3   ← negative sequence

Physically:

  • Positive sequence is the normal balanced set, a-b-c rotation. Under healthy conditions it is all that exists.
  • Negative sequence is a balanced set rotating a-c-b. It appears only under unbalance, and it induces double-frequency currents in a generator rotor — which is why machines have a negative-sequence overcurrent relay (device 46).
  • Zero sequence is three equal, in-phase phasors. It needs a return path, so it only flows where there is a ground or a neutral. Its presence is a ground fault, which is what a 51N element detects.
Why relay engineers care: a residual connection of three CTs sums to 3I0. Zero in a healthy system, non-zero the instant a phase touches ground. That single measurement is the foundation of all ground-fault protection.

The three-phase fault is usually — but not always — the largest. When Z0 < Z1, which happens close to a solidly grounded wye-delta transformer, an SLG fault exceeds the three-phase fault. Breaker duty must be checked against both.

Worked example

At a 138 kV bus: Z1 = Z2 = j0.25 pu, Z0 = j0.15 pu, prefault voltage 1.0 pu, base current 418 A. Compare a bolted three-phase fault with a bolted single line-to-ground fault.

  1. 3Φ: I = 1.0/0.25 = 4.00 pu → 4.00 × 418 = 1,672 A.
  2. SLG: I = 3(1.0)/(0.25 + 0.25 + 0.15) = 3/0.65 = 4.615 pu → 1,929 A.

The ground fault is 15% larger than the three-phase fault, because Z0 is smaller than Z1 at this bus. Sizing the breaker on the three-phase value alone would under-rate it.

Field notes

  • Fault current decays. A synchronous machine presents X″d (subtransient, first cycle), then X′d (transient, a few cycles), then Xd (steady state). Breaker duty uses the subtransient value; relay coordination often uses the transient one.
  • Arcing faults are not bolted. Real fault impedance, especially for a downed conductor on dry ground, can be tens of ohms — low enough to be dangerous, too low a current for an overcurrent relay to see. This is the high-impedance fault detection problem and it is still not fully solved.
  • Inverter-based resources break the assumptions. A synchronous machine delivers 5–8× rated current into a fault. An inverter is current limited to about 1.1–1.2× and may contribute almost no negative sequence. Protection schemes tuned for machines can fail to pick up on an inverter-dominated network — an active area of standards work in ERCOT and elsewhere.

How each fault wires the sequence networks together

This is the part that is hard to hold in your head from equations alone. Each fault type connects the three sequence networks in a different topology, and the fault current formula falls straight out of the resulting series/parallel combination.

Check yourself

Z1 = Z2 = 0.2 pu, Z0 = 0.1 pu, E = 1.0 pu, bolted SLG. Find If.

If = 3E/(Z1+Z2+Z0) = 3/0.5 = 6.0 pu.

Why is the delta winding of a Dyn transformer described as "blocking" zero sequence?

Zero-sequence currents are equal and in phase in all three phases, so they need a return path. A delta winding provides a closed loop for them to circulate within the delta, but no path out to the external system. Zero-sequence current on the wye side therefore never appears on the delta side — the transformer isolates ground faults between voltage levels.

Under what condition does an SLG fault exceed a three-phase fault?

Compare 3E/(Z1+Z2+Z0) with E/Z1. With Z2 = Z1, SLG wins whenever Z0 < Z1 — typical right at the terminals of a solidly grounded wye-delta transformer.
