Phase-Locked Loop (PLL) Basics

PLLs are fundamental building blocks for frequency synthesis, clock recovery, and demodulation. They use feedback to lock the output phase to a reference signal.

Core Function
fout = N × fref
Phase Detector
Compares ref and feedback
Loop Filter
Smooths control voltage
VCO
Voltage-controlled oscillator
Key Insight: The PLL is a negative feedback system that adjusts VCO frequency until the phase difference between reference and feedback signals is constant. The divider (N) sets the frequency multiplication ratio.

PLL Parameters

Parameter Symbol Description
Phase Detector Gain KPD Volts per radian of phase error
VCO Gain KVCO Hz per volt of control voltage
Loop Bandwidth fBW Sets lock time and phase noise filtering
Damping Factor ζ Controls overshoot (typical: 0.707)
Natural Frequency ωn √(KPD×KVCO/N)
Design Trade-off: Wide loop bandwidth = fast lock time but passes more reference spur. Narrow bandwidth = cleaner output but slower settling. Typical: fBW ≈ fref/20.
