📖 Glossary of Terms & Acronyms (Click to expand)

AC - Alternating Current: Current that periodically reverses direction

ADC - Analog-to-Digital Converter: Converts continuous signals to discrete values

Av - Voltage Gain: Output voltage divided by input voltage

BJT - Bipolar Junction Transistor: Current-controlled transistor (NPN/PNP)

BOM - Bill of Materials: List of components for manufacturing

BW - Bandwidth: Frequency range where gain is above -3dB

CB - Common Base: BJT configuration with base at AC ground

CC - Common Collector: BJT configuration (Emitter Follower)

CE - Common Emitter: BJT configuration with emitter at AC ground

CMRR - Common-Mode Rejection Ratio: Ability to reject common signals

DAC - Digital-to-Analog Converter: Converts digital values to analog

DC - Direct Current: Constant current flow in one direction

DRC - Design Rule Check: PCB manufacturing constraint verification

EMI - Electromagnetic Interference: Unwanted EM energy coupling

ESR - Equivalent Series Resistance: Resistive component of capacitors

fc - Cutoff Frequency: -3dB point of a filter

FET - Field Effect Transistor: Voltage-controlled transistor

GBW - Gain-Bandwidth Product: Op-amp unity gain frequency

gm - Transconductance: Output current per input voltage (S or mS)

IC - Integrated Circuit: Multiple components in single package

JFET - Junction FET: Depletion-mode FET with PN junction gate

LDO - Low Dropout Regulator: Voltage regulator with low Vin-Vout margin

MFB - Multiple Feedback: Active filter topology

MOSFET - Metal-Oxide-Semiconductor FET: Enhancement/depletion FET

NMOS - N-channel MOSFET: Enhancement mode N-type MOSFET

Op-Amp - Operational Amplifier: High-gain differential amplifier IC

PCB - Printed Circuit Board: Substrate with copper traces

PDN - Power Delivery Network: Power supply distribution system

PMOS - P-channel MOSFET: Enhancement mode P-type MOSFET

PSRR - Power Supply Rejection Ratio: Immunity to supply noise

Q - Quality Factor: Selectivity of resonant circuits

re - Emitter Resistance: Dynamic resistance ≈ 26mV/Ie

RFC - Radio Frequency Choke: Inductor blocking RF, passing DC

RMS - Root Mean Square: Effective value of AC waveform

SI - Signal Integrity: Quality of electrical signals on PCB

SMPS - Switched-Mode Power Supply: Efficient switching regulator

SNR - Signal-to-Noise Ratio: Desired signal vs noise power

SPICE - Simulation Program with IC Emphasis: Circuit simulator

SR - Slew Rate: Maximum voltage change rate (V/µs)

THD - Total Harmonic Distortion: Nonlinearity measure

τ (tau) - Time Constant: RC or L/R time constant

VCO - Voltage-Controlled Oscillator: Frequency varies with voltage

Vt - Thermal Voltage: kT/q ≈ 26mV at room temperature

Zin - Input Impedance: Resistance seen at input terminal

Zout - Output Impedance: Source resistance at output

PCB Design & Signal Integrity

Key principles from Rick Hartley, Eric Bogatin, and Altium Academy

🔌 Return Current Paths (Rick Hartley)

Key Insight: "The real cause of signal integrity issues is not the voltage or current in the trace, but the field that carries energy."

  • Return current follows the path of least impedance, not resistance
  • At high frequencies (>~10kHz), return current flows directly beneath the signal trace
  • Place signal traces one dielectric layer from reference plane
  • Broken return paths create EMI and signal integrity problems
  • Layer transitions require stitching vias near signal vias

4-Layer Stackup Best Practice

Layer 1: Signals    ← 5-8 mil
Layer 2: GND Plane  ← Reference for L1
        ~40 mil core
Layer 3: Power Plane ← Can be return path
Layer 4: Signals    ← 5-8 mil from L3

Improved: Signals on outer layers, both ground planes

📡 Signal Integrity Fundamentals (Eric Bogatin)

Pathological Design Features to Avoid:

  • Vias in signal path add inductance (~0.5-1nH typical)
  • Stubs from unused via pads cause reflections
  • Reference plane gaps break return path
  • Right-angle bends cause impedance discontinuity (use 45° or curves)
  • Long parallel traces create crosstalk (3× trace width spacing)

Rise Time Rule:

If trace length > (rise time × 6 inches/ns), treat as transmission line

Transmission Line Equations

Microstrip Z₀ ≈ 87/√(εr+1.41) × ln(5.98h/(0.8w+t))

Stripline Z₀ ≈ 60/√εr × ln(4h/(0.67π(0.8w+t)))

Where:
  h = dielectric height (mils)
  w = trace width (mils)
  t = copper thickness (mils)
  εr = dielectric constant (~4.3 for FR4)

⚡ Power Delivery Network (Altium Academy)

PDN Design Goals:

  • Low impedance from DC to highest switching frequency
  • IR drop < 5% of supply voltage to load
  • Ripple voltage must be within IC tolerance
  • Current density: IPC-2152 guidelines for trace width

Decoupling Strategy:

  • Bulk caps (10-100µF) near power entry
  • Mid-range caps (0.1-1µF) distributed across board
  • High-frequency caps (100pF-10nF) at each IC power pin
  • Place caps on same side as IC, minimize via inductance

🛡️ EMI Mitigation Checklist

☐ Solid ground plane under all high-speed signals

☐ No splits in ground plane under sensitive traces

☐ Stitching vias every λ/20 along board edges

☐ Minimize loop area between signal and return

☐ Filter power at entry (ferrite bead + capacitor)

☐ Clock traces short and series-terminated

☐ Separate analog and digital grounds with single-point star

☐ Guard rings around sensitive analog circuits

☐ 3W spacing rule: Edge-to-edge = 3× trace width for <70% crosstalk reduction

☐ Controlled impedance on differential pairs (±10%)
