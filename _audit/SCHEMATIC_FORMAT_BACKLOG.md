# Schematic format backlog: circuits drawn outside AD.Schematic

Generated by `tools/check-schematic-format.js` and git history on 2026-09-04.
Regenerate with the scratch logger; the gate itself reads `tools/schematic-format-baseline.json`.

## What this is

Every literal `<svg>` in a lesson that draws a circuit outside the schematic
system: it carries `class="circuit-diagram"`, or it paints with hard-coded colour
attributes and contains an op-amp triangle, a resistor zig-zag, or two or more
circuit labels. Such a figure has no course palette, no component symbols from
the library, no connectivity validation, and its labels copy out as loose text.

**333 figures in 141 lessons.** 21 lessons use `schematic-container` + `AD.Schematic`.

## How to fix one

M01 L06 is the worked example (commit 5dbc052): replace the `<svg>` with
`<div class="schematic-container" id="sch-..."></div>` plus a `<p class="schematic-caption">`,
and draw it in the lesson script with `AD.Schematic.create(el, {width, height})` -
`opamp` / `opampTerminals`, `resistor` / `capacitor` (they return `pin1`/`pin2`),
`wire`, `junction`, `ground`, `vcc` / `vee`, `nodeLabel`, `text`, `rect`, then
`finalize()`. Colours come from `AD.Schematic.COLORS` (`highlight`, `vcc`, `signal`).
Check the console: `finalize()` reports text-on-keepout and floating pins.
Equations and notes go in the caption, not inside the SVG. Then rerun
`node tools/check-schematic-format.js` and lower the baseline with `--update-baseline`.

## Where they came from

This was checked because it looked as if the style might be a recent regression.
It is not. The initial commit (985cbf9, 2026-08-31) already carried 290 figures
with `class="circuit-diagram"` across 110 lessons, against 20 lessons on
`schematic-container`; the count has moved 290 -> 284 since (two added by later
sessions, six redrawn). Naive `git log -S` blames the module-renumbering commit
for most of them, because it rewrote files past rename detection; the figures
below are instead matched by content against the initial tree.

**330 of 333 figures are original** (present in the initial commit, possibly under another path). The rest were added by the commits listed:
